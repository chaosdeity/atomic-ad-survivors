## 1. 이번 문서가 붙는 실제 게임

**LOCKED — 기존 권위의 재진술:** 현재 골격은 의뢰 → 탐험 → 국지 유한 전투 → 조사 → 선택 → 자율 귀환 → 보고/성장 → 재방문이다. L01의 선택은 호출 보류 또는 기존 대기 유지다. L02 후속 의뢰명은 `분양 주택 기록 대조`이며, 서로 다른 기록 세 개가 독립 저장되고 조사 순서는 자유다. 청소 흔적은 선택 조사다. 미완료 귀환의 진행 보존과 완료 보고의 일회성 성장은 현재 구현 기록에 있다. [PE01; U34/U35]

이 문서는 적 생성·성장 수치·저장 스키마·상호작용·경로를 변경하지 않는다. 문구와 감정의 배치를 제안한다. 기존 기록의 정확한 런타임 문자열과 이 초안의 문안을 일대일 대조하는 작업은 **확인 필요 / D03**이다. U35가 기록의 존재와 차이를 설명한다고 해서 여기서 만든 세부 문장이 이미 게임에 있다고 주장하지 않는다.

특히 아래 L02 E1/E2/E3는 **기존 세 기록 슬롯에 검토할 서사 기능 후보**다. 슬롯 번호는 편집상 참조일 뿐 실제 오브젝트의 현재 의미를 검증 완료한 매핑이 아니다. 원문과 맞지 않으면 실제 텍스트를 우선 읽고 문안을 재배치한다. 새 슬롯·새 실종자·새 가족관계·새 저장 필드를 만들지 않는다.

20개 beat는 편집용 장면 단위다. 전투와 선택 조사, 중간 귀환은 탐험 중 끼어들 수 있다. 나열 순서를 강제 동선이나 완료 조건으로 바꾸지 않는다.

## 3. L01 — 기록이 이상하다는 감각

### B01. QUEST OFFER — 보고에 쓸 수 있는 말

**LOCATION:** R08-L01 침묵 보급소, 현재 미나 의뢰 접점.

**PLAYER ACTION:** 첫 의뢰를 받고 현재 목표를 확인한다.

**NPC INVOLVEMENT:** 미나는 쓸 수 있는 확인을 요구한다. 윤서는 확인하지 않은 사람까지 보고에 넣지 않으려 한다.

**OBSERVATION:** 미나는 빈손 귀환을 금지하지 않는다. 대신 본 것과 추측을 나누기를 원한다.

**CONTRADICTION:** 사람을 지키려면 신중해야 하지만 보급소는 오늘 판단해야 한다.

**EMOTIONAL BEAT:** 익숙한 동료 사이의 짧은 마찰. “많이 가져와”보다 “어디까지 봤는지 말해”가 먼저다.

**CHOICE:** 현재 의뢰 수락과 출격. 새 도덕 선택 메뉴는 추가하지 않는다.

**CONSEQUENCE:** 목표는 누군가의 가족을 찾아 주는 일이 아니라 기록을 확인하는 일로 좁혀진다.

**PERSISTENT MEMORY:** 기존 수락 상태만 사용한다. 별도 관계 기억 없음.

**NEXT QUESTION:** 미나는 왜 ‘확인했다’는 말을 이렇게 조심해서 쓰는가?

대사 후보 / SUPPORTED EXPANSION: 미나 “읽은 데까지만 가져와. 사람까지 확인했다고 쓰진 말고.” 윤서 “그건 나도 싫어.”

### B02. FIRST FIELD ENTRY — 도움은 실제로 온다

**LOCATION:** R01-L01 침묵 가장자리, 기존 진입과 생활 서비스 오브젝트 주변.

**PLAYER ACTION:** 주택가에 들어가 현재 접근 가능한 도움과 기록을 살핀다.

**NPC INVOLVEMENT:** 윤서의 관찰. 새 주민을 세우지 않는다.

**OBSERVATION:** 집의 서비스가 실제로 도움을 제공하거나 접근을 열어 주는 기존 맥락을 드러낸다. [PE01]

**CONTRADICTION:** 도움이 된다는 사실은 그 서비스가 나를 정확히 안다는 증거가 아니다.

**EMOTIONAL BEAT:** 안도한 직후 자기 이름이나 역할을 확인하려는 불편함.

**CHOICE:** 둘러보거나 현재 허용된 상호작용을 한다. 새 강제 등록을 발생시키지 않는다.

**CONSEQUENCE:** 캠페인이 단순히 사람을 죽이려는 적이라는 첫 가정에 틈이 생긴다.

**PERSISTENT MEMORY:** 실제로 확인한 오브젝트/의뢰 진행 범위만. 별도 영구등록 없음.

**NEXT QUESTION:** 이 도움은 누구에게 제공된 것으로 기록될까?

### B03. FIRST RECORD — 받았다는 기록

**LOCATION:** L01의 기존 수령 기록 접점.

**PLAYER ACTION:** 기록을 읽고 어떤 절차가 완료됐다고 적혔는지 확인한다.

**NPC INVOLVEMENT:** 윤서. 현장에 없는 미나의 무전을 신규 필수 기능으로 가정하지 않는다.

**OBSERVATION:** 수령에 관한 기록이 존재한다. 기록의 주체와 기록이 주장하는 사람은 구분한다.

**CONTRADICTION:** 수령 절차의 기록은 그 사람이 지금 여기 있다는 직접 확인이 아니다.

**EMOTIONAL BEAT:** 사소한 행정 문장 하나가 사람보다 또렷하게 남아 있는 불쾌함.

**CHOICE:** 읽은 사실을 인정하되 실제 가족·생사 판단은 보류한다. 이는 해석 공간이지 새 UI 선택이 아니다.

**CONSEQUENCE:** 다음 인증 기록을 볼 이유가 생긴다. 단순 두 번째 수집물이 아니다.

**PERSISTENT MEMORY:** 기존 수령 기록 조사 상태. 인물 확인 완료로 저장하지 않는다.

**NEXT QUESTION:** 받았다고 적힌 사람과 인증된 사람은 같은 범위를 가리키는가?

### B04. SECOND CONTRADICTION — 인증은 누구를 확인했나

**LOCATION:** L01의 기존 인증 기록 접점.

**PLAYER ACTION:** 수령 기록과 인증 기록을 대조한다. 먼저 인증을 봤다면 수령을 나중에 대조해도 된다.

**NPC INVOLVEMENT:** 윤서. 비교 해설은 관찰한 두 기록 안에서만 나온다.

**OBSERVATION:** 서로 다른 절차가 같은 생활 사건을 설명하지만, 절차가 확인한 범위는 같지 않을 수 있다. 세부 문안은 D03에서 실제 문자열과 대조한다.

**CONTRADICTION:** 확인 표시가 두 개라는 이유만으로 독립된 사람 확인이 두 번 이뤄진 것은 아니다.

**EMOTIONAL BEAT:** ‘기록 하나가 낡았다’는 가벼운 설명으로 끝내기 어려워진다.

**CHOICE:** 무엇이 서로 맞으며 무엇은 여전히 맞춰지지 않는지 구분한다.

**CONSEQUENCE:** 호출 처리에 앞서 기록과 인간관계를 혼동하지 않을 근거가 생긴다.

**PERSISTENT MEMORY:** 기존 두 조사 상태. 실제 인물 동일성 flag를 새로 만들지 않는다.

**NEXT QUESTION:** 이 절차는 사람을 찾는가, 일치하는 역할을 찾는가?

### B05. COMBAT — 확인받으려는 것이 아니라 빠져나오기

**LOCATION:** L01의 현재 국지 전투 발생 구역. B03/B04 사이 또는 이후에 접할 수 있다.

**PLAYER ACTION:** 현재 수동 유지 공격과 회피로 유한한 집행 개체에 대응한다.

**NPC INVOLVEMENT:** 윤서. MAIL-LOOP의 음성/기록 역할을 전투 적과 무조건 동일시하지 않는다.

**OBSERVATION:** 전투 개체의 행동을 주소·등록·동선 보정 같은 지역 절차와 연결해 읽을 수 있다. [UC; B1]

**CONTRADICTION:** 같은 생활 체계가 도움을 제공하면서 원하지 않는 확인과 배치도 요구한다.

**EMOTIONAL BEAT:** 친절을 거절하는 데 물리적인 힘이 필요하다는 불편함.

**CHOICE:** 현재 전투 규칙 안에서 대응하거나 물러난다. 새 전멸 목표나 처치 수 해금을 넣지 않는다.

**CONSEQUENCE:** 해당 국지 압력이 줄어도 모든 집의 기록이 고쳐지지는 않는다.

**PERSISTENT MEMORY:** 실제 발생원·전투·선택 상태의 현재 계약만 사용한다. 방문을 넘어 모든 적이 영구 제거된다고 말하지 않는다.

**NEXT QUESTION:** 집을 조용하게 만드는 것과 집이 내린 판단을 바꾸는 것은 같은가?

### B06. OPTIONAL CLUE — 먼저 붙어 있던 이름

**LOCATION:** L01의 선택적 옛 이름표 접점.

**PLAYER ACTION:** 필요하면 이름표를 읽고 다른 기록과 대조한다.

**NPC INVOLVEMENT:** 윤서의 잠깐 멈춤. 복희의 직접 등장이나 새 회상 컷신은 필요하지 않다.

**OBSERVATION:** 현재 등록 문구와는 다른 시점의 이름 흔적을 본다. 정확한 문자열과 표현은 실제 원문 우선이다.

**CONTRADICTION:** 오래됐다는 이유만으로 더 진실한 이름이라고 판정할 수 없다. 새 이름이 붙기 전에도 기록은 틀릴 수 있다.

**EMOTIONAL BEAT:** 윤서가 읽는 속도가 잠깐 느려진다. 개인 과거를 설명하지 않는다.

**CHOICE:** 선택 조사 여부. 조사하지 않아도 필수 의뢰의 의미와 진행은 성립해야 한다.

**CONSEQUENCE:** ‘하나가 진짜고 하나가 가짜’라는 단순 해석 대신 시간과 주체를 대조하게 된다.

**PERSISTENT MEMORY:** 기존 선택 흔적의 확인 범위만. 윤서의 가족/어린 시절과 동일한 이름이라는 사실을 새로 넣지 않는다.

**NEXT QUESTION:** 이름이 바뀌었다면 사람도 바뀐 것인가, 역할만 갱신된 것인가?

### B07. CHOICE — 호출을 멈출지, 기다림을 유지할지

**LOCATION:** 기존 MAIL-LOOP 관련 호출 처리 접점.

**PLAYER ACTION:** 호출 보류 또는 기존 대기 유지를 고른다.

**NPC INVOLVEMENT:** MAIL-LOOP는 절차를 말하고 윤서는 처리 범위를 확인한다. 목소리의 존재를 생존자의 존재로 바꾸지 않는다.

**OBSERVATION:** 기다리는 주소와 확인되지 않은 사람 사이의 차이가 남아 있다.

**CONTRADICTION:** 멈추면 해결한 것처럼 느껴지고, 유지하면 돌본 것처럼 느껴지지만 어느 쪽도 사람의 의사를 확인한 선택은 아니다.

**EMOTIONAL BEAT:** 정답이 아니라 자신이 감당할 판단을 고르는 순간.

**CHOICE:** 기존 두 선택 그대로. ‘가족 승인’, ‘주소 삭제’, ‘사람 구출’로 개명하지 않는다.

**CONSEQUENCE:** 호출 처리 상태는 달라진다. 기록의 진실이나 실제 가족관계는 확정되지 않는다.

**PERSISTENT MEMORY:** 현재 저장되는 호출 선택. 관계·생사·전역 서비스 변경을 붙이지 않는다.

**NEXT QUESTION:** 돌아가서 미나에게 무엇을 했다고 말할 것인가?

### B08. VOLUNTARY RETURN — 끝내기 전에 돌아올 수 있다

**LOCATION:** 현재 L01 귀환 접점 → R08-L01.

**PLAYER ACTION:** 조사 도중 또는 현재 보고 조건을 채운 뒤 자율 귀환한다.

**NPC INVOLVEMENT:** 윤서가 귀환을 결정한다. 미나가 타이머로 끌어내지 않는다.

**OBSERVATION:** 현장을 떠나도 본 내용은 보존되며, 미완료인 것은 미완료로 남는다.

**CONTRADICTION:** 멈추지 않고 더 보는 행동만 책임감인 것은 아니다. 돌아와 판단을 나누는 것도 필요하다.

**EMOTIONAL BEAT:** 포기가 아니라 돌아갈 곳을 사용하는 행동.

**CHOICE:** 지금 돌아가기 또는 현재 허용된 탐험 계속하기.

**CONSEQUENCE:** 미완료면 완료 보고와 보상을 받지 않는다. 완료 상태면 기존 보고로 이어진다.

**PERSISTENT MEMORY:** 기존 부분 진행/선택 보존 계약. 새 시간 경과 피해 없음.

**NEXT QUESTION:** 내가 본 범위로 누가 무엇을 결정할 수 있을까?

### B09. REPORT — 같은 종이를 다른 목적으로 읽는다

**LOCATION:** R08-L01 미나 보고 접점.

**PLAYER ACTION:** 기존 조건에 맞춰 보고하거나 미완료 상태를 확인한다.

**NPC INVOLVEMENT:** 미나는 사용할 수 있는 결론을 묻고, 윤서는 확인한 범위를 말한다.

**OBSERVATION:** 호출 처리를 끝냈다는 사실과 그 집의 사람을 확인했다는 말은 다르다.

**CONTRADICTION:** 윤서가 ‘모른다’고만 하면 미나는 다음 판단을 할 수 없다. 미나가 ‘처리했다’고만 하면 윤서가 남겨 둔 질문이 지워진다.

**EMOTIONAL BEAT:** X1. 서로를 불신하지 않아도 말이 부딪힌다.

**CHOICE:** 새 정답 대화 선택지를 추가하지 않는다. 기존 선택/조사 상태를 반영해 보고 문장을 달리 쓰는 후보다.

**CHOICE:** 선택 탐험과 귀환. 다음 Local을 새로 여는 상호작용을 넣지 않는다.

**CONSEQUENCE:** 전체 게임 엔딩이 아니라 이 조사 구간의 끝으로 남는다. 새 정보가 없어도 이전 장면의 의미가 달라진다.

**PERSISTENT MEMORY:** 현재 조사/보고 상태에 따른 반복 안전 반응. 방문 횟수·새 관계 flag는 승인 전 가정하지 않는다.

**NEXT QUESTION:** 밖으로 나가고 싶은 사람이 있다면, 기록을 고치는 것만으로 그 사람을 도울 수 있을까?

## 5. L02 조사 순서 6종 검산

아래는 제안 문안의 논리 검산이며 실행 테스트 결과가 아니다. E1=등록 주장 범위, E2=다른 위치의 반복, E3=프로필/역할 반복 가설이다. 각 기록은 혼자 읽어도 질문 하나가 생기고, 이미 읽은 기록이 있을 때만 비교 문장을 허용한다.

| 순서 | 첫 기록의 질문 | 두 번째 기록이 깨는 가정 | 세 번째 기록으로 가능한 결론 |
|---|---|---|---|
| E1 → E2 → E3 | 이름이 있다는 것이 관계 확인인가? | 한 집의 국지 오류만은 아니다. | 반복된 역할 설명일 가능성을 검토할 수 있다. 실제 관계는 미확인. |
| E1 → E3 → E2 | 등록 주장은 어디까지 유효한가? | 비슷한 프로필 여러 개가 독립 확인 여러 번은 아니다. | 다른 위치에도 반복이 있어 단일 기록의 문제로 닫기 어렵다. |
| E2 → E1 → E3 | 다른 위치에서 왜 같은 표현을 쓰나? | 같은 이름 표현만으로 같은 사람이라고 할 수 없다. | 사람보다 역할 설명이 반복됐을 가능성을 남긴다. |
| E2 → E3 → E1 | 반복은 사람의 이동 흔적인가? | 반복된 설명이 실제 이동을 증명하지는 않는다. | 등록 주장의 범위를 확인해 관계·동의 확정을 막는다. |
| E3 → E1 → E2 | 프로필이 반복되면 사람도 같은가? | 이름이 있어도 당사자 확인은 따로 필요하다. | 한 위치의 낡은 프로필 문제를 넘어선 반복임을 대조한다. |
| E3 → E2 → E1 | 같은 설명이 왜 여러 번 나오나? | 복제 가능성뿐 아니라 적용 위치가 다른 문제가 있다. | 기록의 주장과 실제 인간관계를 끝까지 나누어 보고한다. |

공통 종착점은 **“한 집의 오류로만 설명하기 어렵다. 하지만 실제 가족관계는 확인되지 않았다.”**다. 서로 다른 순서가 같은 최종 범위에 도달해도, 도중에 깨지는 가정은 다르다. 청소 흔적은 어느 시점에 보든 부재 해석을 보완할 뿐, 위 결론의 필수 열쇠가 아니다.

## 6. 선택 × 선택 흔적의 네 가지 보고 기억

| L01 선택 / L02 흔적 | 귀환에서 인정할 것 | 인정하지 않을 것 | 재방문 payoff |
|---|---|---|---|
| 호출 보류 / 청소 미확인 | 호출을 멈췄고 기록의 반복을 확인했다. | 주소 삭제, 사람 구조, 흔적 삭제 원인. | 멈춘 목소리와 남은 기록이 별개임을 본다. |
| 호출 보류 / 청소 확인 | 호출과 기록의 부재를 서로 다른 문제로 본다. | 청소 행위자의 신원·악의, 영구 해방. | 조용함과 안전함을 같은 것으로 보지 않는다. |
| 대기 유지 / 청소 미확인 | 확인되지 않은 사람을 기다리는 절차를 유지했다. | 실제 사람이 돌아왔다는 사실. | 계속되는 호출을 생존 증명으로 듣지 않는다. |
| 대기 유지 / 청소 확인 | 호출은 계속되며 현장의 흔적은 변할 수 있음을 안다. | 같은 사람이 계속 살고 있다는 단정. | 기다리는 주소와 사라질 수 있는 흔적의 비대칭을 읽는다. |

미나의 평가를 선/악 판정으로 만들지 않는다. 네 분기 모두 확인한 행동을 인정하고, 각자 남긴 미확인 부분을 묻는다. 초반 선택 때문에 새 주민이 죽거나 사라졌다는 처벌을 붙이지 않는다.

## 7. 검증 계획과 완료 판정의 범위

문안 적용 전에는 실제 L01/L02 오브젝트 이름·조사 본문·일지·선택·보고 문자열을 읽어 E1/E2/E3 매핑을 확정해야 한다. 기존 문구가 이미 같은 증거 기능을 갖고 있다면 바꾸기보다 윤서/미나 반응만 보강한다. 정사에 없는 사건을 요구하는 문안은 삭제하거나 CANDIDATE로 남긴다.

후속 테스트 항목:

1. L02의 6개 순서에서 미관측 기록을 먼저 아는 대사가 나오지 않는다.
2. L01 필수 기록과 선택적 이름표, L02 세 기록과 선택 청소 흔적의 조건을 혼동하지 않는다.
3. 부분 조사 후 귀환·저장·재시작·후속 조사가 기존 진행을 보존한다.
4. L01 두 선택과 L02 흔적 유무의 4조합에서 보고·재방문 문장이 실제 상태와 맞는다.
5. 반복 보고가 성장 보상을 중복 지급하지 않는다. 문구 추가로 완료 조건을 바꾸지 않는다.
6. 전투가 국지 유한 구조를 유지한다. timer·강제 첫 인양·보스·새 웨이브를 넣지 않는다.
7. 플레이어에게 ‘확인된 것/기록이 주장한 것/아직 모르는 것’을 설명하게 한다. 실제 가족과 윤서의 과거를 확정해 이해하면 문구를 수정한다.

문서상 장면·분기·순서 논리 검토: 완료. 런타임 문자열 바인딩·실행 회귀·사용자 감정 전달 검증: 미실행 / 후속 과제. 이 구분을 유지한 상태로 P0 제작 검토에 전달한다.
