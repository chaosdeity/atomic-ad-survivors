# 마를 자리

미나가 숟가락을 입에 가져가던 참에 윤서가 가방을 카운터에 올렸다. 그릇이 작은 소리를 내며 밀렸다.

“옆에.”

윤서는 가방을 반대쪽으로 들었다.

“거긴 종이.”

윤서는 어깨에 걸린 끈을 풀었다. 가방을 놓을 만한 면마다 미나의 물건이 먼저 와 있었다. 바닥에 세워 놓고 안에서 젖은 종이를 꺼냈다. 접힌 자리에 손가락을 넣자 미나가 그릇을 뒤로 당겼다.

“지금 읽어?”

“다 마르면.”

“그럼 왜 지금 펴.”

접힌 면이 손가락에 달라붙었다. 윤서는 카운터 끝을 내려다보았다. 펼치면 밥그릇 옆까지 닿을 것 같았다.

“조금만 빌릴게.”

미나는 그릇을 자기 쪽으로 당겼다. 숟가락은 아직 깨끗했다.

복희가 마른 천을 들고 왔다.

“문지르진 마라. 이쪽 줘 봐.”

윤서가 종이를 건넸다. 복희는 천 위에 한쪽 면을 놓고 접힌 끝을 가리켰다.

“여기도 펴도 되니?”

“이름은 안 읽고.”

“말리려고.”

윤서는 천천히 손가락을 뺐다. 복희는 종이를 뒤집지 않고 붙은 가장자리만 떼어 냈다.

미나가 숟가락을 그릇에 내려놓았다.

“내가 볼 건 앞쪽이야?”

“응. 뒤쪽은 아직.”

“앞쪽만 볼게. 자리 좀.”

윤서는 가방 끈에 한쪽 팔을 넣었다. 복희가 접힌 면을 펴다 말고 말했다.

“이 끝 좀 잡아 줄래.”

다시 팔을 뺐다. 윤서가 한쪽을 잡자 반대 끝이 살짝 말려 올라왔다.

“그냥 눌러. 꽉 말고.”

윤서는 손가락 두 개를 내려놓았다.

“너 아직 안 먹었어?”

“먹으려고 했지.”

미나는 그릇을 들고도 앉지 못했다. 종이와 천이 차지한 쪽에 팔꿈치를 놓을 데가 없었다.

“그릇 좀 받아.”

윤서가 남은 손을 내밀었다.

“내가 앉을 때까지만.”

미나는 펜과 작은 물건들을 옆으로 밀었다. 복희가 천의 한쪽을 접어 주자 카운터 끝에 팔꿈치를 놓을 자리가 났다. 윤서의 한 손은 종이 위에, 다른 손은 밥그릇 밑에 남아 있었다.

“됐어.”

미나가 그릇 쪽으로 손을 내밀었다. 식은 밥이 숟가락에 한 덩어리로 올라왔다.

## 이 장면이 놓이는 자리

L01/L02의 특정 조사 결과를 아는 필수 장면이 아니다. 윤서가 자율 귀환한 뒤, 허브의 해당 인물·생활 연출을 허용할 수 있는 시점에 선택적으로 배치할 후보이다. 이 장면을 보지 않아도 메인 의뢰와 세 기록의 질문은 이해할 수 있다.

종이의 뒤쪽 이름이 누구인지, 어떤 과거 사건이 적혀 있는지는 쓰지 않았다. 후속 비밀을 암시하기 위해 감추는 장치도 아니다. 남의 자료를 다루는 일에는 읽는 범위가 있다는 현재의 작은 부탁이다. 문학적 소품에 별도 인벤토리 ID나 퀘스트 완료 조건을 붙이지 않는다.

시작은 자료를 넘기려는 윤서가 미나의 식사 자리를 차지한 순간이다. 끝은 윤서가 떠나려던 팔을 빼고 실제 손일을 맡은 순간 뒤에 온다. 이 변화는 별도 신뢰 수치나 새 호감도 보상 없이도 장면 안에서 확인된다. 장기 관계 기억으로 남기려면 D08과 실제 저장·노출 설계가 필요하다.

## 인물의 다른 부탁

| 인물 | 지금 원하는 것 | 상대에게 직접 말하지 않는 것 | 말 대신 하는 일 |
|---|---|---|---|
| 윤서 | 젖은 자료를 놓고 필요한 앞면만 넘기기 | 정리하지 못한 부분을 남이 먼저 읽을까 걱정함 | 떠나려던 팔을 빼고 종이 끝을 누름 |
| 미나 | 일을 받을 자리를 만들고 밀린 식사를 시작하기 | 돌아온 사람이 자기 손일도 잠깐 맡아 주었으면 함 | 그릇을 당기고, 앉을 때까지만 받아 달라고 요청 |
| 복희 | 붙은 종이를 찢지 않고 말리기 | 이름을 알아야만 도울 수 있는 것은 아님 | 뒤집어 읽지 않고 가장자리만 펴며 윤서의 손을 빌림 |

이 표는 작가의 해설이다. 원고 뒤에 등장인물이 이 뜻을 말하는 대사를 추가하지 않는다. 미나가 선한 사람이라는 결론이나 윤서가 성장했다는 결론도 본문에서 설명하지 않는다.

## 여덟 질문 검수

1. **이 장면 전에 믿거나 기대한 것:** 윤서는 가방에서 자료를 꺼내 건네면 자기 일이 끝날 수 있다고 기대한다. 미나는 막 식사를 시작하려 했다.
2. **끝에서 달라지는 것:** 윤서는 종이와 그릇을 잠깐 맡고, 미나는 처음 하려던 식사를 시작한다. 자료의 내용은 해결되지 않아도 일을 나누는 동작은 달라진다.
3. **누가 무엇을 원하는가:** 윤서는 놓을 자리와 읽을 범위, 미나는 앉을 자리와 식사, 복희는 종이를 펴는 데 필요한 손을 원한다.
4. **누가 또는 무엇이 막는가:** 좁은 카운터와 겹친 손일, 먼저 끝내고 싶어 하는 각자의 순서가 서로를 막는다. 새로운 적이나 재난은 없다.
5. **말하지 않는 것은 무엇인가:** 윤서는 자료를 맡기면서 그 이후의 일까지 맡길 생각은 하지 못했다. 미나는 큰 위로나 사과 대신 잠깐 그릇을 받아 달라고 한다.
6. **플레이어가 직접 하는 행동:** 허브에 돌아와 선택 장면에 접근하고 머물거나 떠난다. 연출 속 종이·그릇 동작은 새 미니게임 입력이 아니라 장면 행동 후보이다. 세부 상호작용으로 전환하려면 별도 설계가 필요하다.
7. **감정을 대신하는 사물:** 처음 놓을 곳이 없던 가방, 아직 깨끗한 숟가락, 종이 끝을 누르는 두 손가락, 마지막 식은 밥.
8. **끝까지 설명하지 않을 것:** 종이에 적힌 이름의 신원, 새 가족관계, 과거 희생자, 세 사람의 속마음을 전지적으로 확정한 해설.

## 플레이와 노출

권장 형식은 짧은 선택형 허브 interlude다. 원고를 대사와 짧은 동작으로 나눠도 되고, 선택 열람의 산문으로 검토할 수도 있다. 현재 엔진에 산문 열람기·음성·자동 카메라가 있다는 가정은 하지 않는다.

지나가는 플레이에는 핵심 목표를 숨기지 않는다. 장면을 마치지 않고 떠나도 기존 의뢰·보상·다음 출격은 그대로다. 종이를 말리는 데 시간을 기다려야 하는 새 진행 gate는 없다. 미나의 식사를 놓쳤다고 굶주림 페널티를 만들지 않는다.

반복 노출에는 주의가 필요하다. 새 일회성 장면 flag가 승인되지 않았다면 매 귀환마다 같은 젖은 종이를 처음 받은 것처럼 재생하지 않는다. 실제 구현 단계에서 기존 상태로 반복 안전하게 구성할 수 있는지 먼저 확인한다. 불가능하면 이 장면의 적용을 보류하고 원고 후보만 보존한다.

## 세 차례 퇴고 이력

완결 초고를 쓴 뒤 목소리·subtext 수정본과 문장 퇴고본을 각각 만들고 차이를 확인했다. 실제 수행한 대표 변경은 다음과 같다.

| 단계 | 문제 | 수정 |
|---|---|---|
| PASS 1: scene truth | 큰 사건 없이도 관계가 바뀌는 구체 동작이 부족함 | 놓을 자리가 없는 가방, 미뤄진 식사, 종이를 펴는 손일로 서로의 요구가 물리적으로 겹치게 함 |
| PASS 2: voice + subtext | 이름을 남기는 의미를 복희가 해설하고, 마지막에 서로 필요한 일을 했다고 요약함 | 복희는 ‘말리려고’라고만 답하고 종이를 뒤집지 않음. 윤서는 떠나려다 작은 부탁 때문에 팔을 다시 뺌. 관계의 의미 해설 삭제 |
| PASS 3: line edit | 막연한 ‘잠깐만’과 중복된 그릇 인수 동작 | 미나는 ‘내가 앉을 때까지만’이라고 범위를 정함. 그릇을 받는 마무리를 합치고 식은 밥의 이미지에서 종료 |

초고에서 빼낸 결론을 문학성을 설명하는 마지막 문장으로 다시 붙이지 않았다. 감정 단어를 지운 자리에 모호한 표정과 긴 침묵만 넣지도 않았다. 세 인물이 실제로 서로의 일을 잠깐 맡는다.

## Literary Pilot Quality Gate

| 항목 | 자체 편집 판정 | 근거와 한계 |
|---|---|---|
| PROSE: 호흡·이미지·수식 절제 | PASS | 좁은 자리에서 손일이 이어질 때 문장이 길어지고 부탁은 짧아짐. 수식어 대신 물건의 자리와 손의 수로 상황을 보여줌 |
| CHARACTER: 음성·욕망·숨김 | PASS | 미나는 자리를, 복희는 손일의 방법을, 윤서는 읽을 범위를 요구함. 세 사람이 모두 멋진 말을 하는 장면이 아님 |
| SCENE: 목적·전후 변화·subtext | PASS | 자료를 넘기고 떠나려던 행동이 실제 도움을 맡는 행동으로 바뀜. 미나의 식사가 끝의 작은 성취 |
| GAME: 플레이 방해 억제 | PASS, 설계 범위 | 선택 장면이며 진행 필수 정보·보상·기다림 gate 없음. 구체 UI와 카메라 적용은 미검증 |
| LITERARY: 두 번째 의미·마지막 이미지 | PASS | 처음 종이를 넘기던 손이 마지막에는 밥그릇을 받음. 남의 일을 받는 범위가 달라지지만 본문은 이를 해설하지 않음 |
| 실제 인물·소품·저장 연결 | 확인 필요 | 복희 배치와 소품, 반복 노출, 새 관계 기억은 현재 runtime에서 검증하지 않았음 |

AI-like prose risk: LOW, 파일럿 본문에 대한 자체 편집 판단. 독립 독자의 화자 식별·낭독 리듬·감정 반응을 측정하지 않았다. 이 원고가 문학상 수준의 외부 심사를 통과했다는 뜻이 아니다.

세 파일럿은 scene truth → voice/subtext → line edit의 세 버전을 작성해 비교했다. 본문에서 ‘마치’, ‘알 수 없는 감정’, ‘그것은’, ‘큰일은 아니었지만’, ‘시스템은 사람을 이해하지 못했다’ 다섯 문자열을 보조 검색했고 해당 패턴은 없었다. 그 결과만으로 문학 품질을 판정하지 않았으며, 기능상 반복 문구와 서술의 반복을 다르게 검수했다.

voice distinction / subtext / rhythm / image-motif / exposition control은 이번 파일럿의 자체 검토에서 PASS다. 독립 심사, 사용자 이해, 실제 게임 UI·저장·조작·성능 검증은 미실행이다. 원문 표본의 AI-like prose 위험과 새 파일럿 본문의 편집 결과를 같은 점수로 섞지 않는다.

남아 있는 편집 검토점은 CH-MINA-01과 HUB-01의 소재 중복이다. Registry는 다른 시점에서만 드러날 요구가 충분하지 않으면 통합 후보로 검토하도록 명시했다. 따라서 아직 쓰지 않은 모든 사이드가 filler 없이 완성됐다고 보고하지 않는다.
