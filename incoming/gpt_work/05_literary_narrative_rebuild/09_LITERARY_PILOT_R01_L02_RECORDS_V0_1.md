## 읽기와 적용의 구분

아래 세 기록은 기존 세 조사 슬롯에 검토할 신규 문안이다. 현재 오브젝트의 원문을 인용한 것이 아니며, 실제 문자열과 슬롯 의미를 대조한 매핑도 아니다. 적용 전에 D03 검증을 해야 한다. 이번 단계는 읽을 수 있는 완성 원고를 만드는 것이며 새 기록 슬롯이나 가족관계의 정사를 만드는 작업이 아니다.

번호 1·2·3은 편집 참조다. 조사 순서를 강제하지 않는다. 각 기록은 단독으로 읽을 수 있고, 두 자료를 비교하는 문안은 이미 읽은 조합에만 붙인다. 청소 흔적은 선택 사항이며 필수 네 번째 기록이 아니다.

# 다른 집의 같은 말

## 1. 다음 부탁

미나는 지난 보고를 한쪽으로 밀어 놓았다.

“이번엔 다른 집.”

“또 같은 서류야?”

“지난번엔 한 집만 봤잖아.”

“거기서 끝났다고 한 적 없어.”

“그래서 이번에 묻는 거야.”

윤서는 종이 끝을 들어 보았다.

“몇 군데?”

“기록 셋. 보는 순서는 네가 정해.”

“중간에 돌아오면 먼저 본 것부터 놓을게.”

“오면 불러. 섞어 놓지만 말고.”

*플레이 연결: 현재 후속 의뢰를 수락한다. 플레이어가 L01 북쪽 관문까지 정상 이동하고 그 위치의 명시적 상호작용으로 L02에 진입한다. 70번 기준의 bounded transition을 따른다. 구역 사이의 연속 보행이나 무료 원격 이동을 새로 요구하지 않는다.*

## 2. 기록 1: 확인란

```text
세대 확인 기록

구성원 항목: 등록 자료 참조.
관계 확인: 이전 구성표 사용.
현장 확인란: 미작성.
인증 상태: 유효.
```

윤서는 유효 표기를 지나 확인란을 보았다. 빈칸에도 테두리는 반듯하게 남아 있었다. 글씨가 흐려서 못 읽는 칸은 아니었다.

## 3. 기록 2: 적용 위치

```text
주택 기록 적용 이력

적용 위치: 현재 주택.
불러온 자료: 다른 주소의 주거 기록.
이름 항목: 불러온 자료 유지.
실제 거주자 대조: 별도 확인.
```

윤서는 다른 주소라는 항목을 두 번 읽었다. 이름을 가져온 곳과 지금 적용한 곳이 따로 적혀 있었다. 윤서는 불러온 자료 쪽으로 눈을 돌렸다가 적용 위치로 돌아왔다.

## 4. 기록 3: 최신

```text
홈 프로필 출력 이력

출력 자료: 저장된 생활 프로필.
새 확인 기록: 없음.
재사용 항목: 가족 구성 설명.
표시 상태: 최신.
```

윤서는 최신이라는 글자에서 그 위로 눈을 돌렸다. 새로 확인한 기록은 없다고 적혀 있었다. 한 줄을 건너 다시 읽어도 두 항목은 같은 화면에 있었다.

## 5. 선택 조사: 청소 흔적

넓게 닦인 면 끝에 가느다란 띠가 남아 있었다. 모서리 아래는 덜 닦였다. 윤서는 몸을 낮춰 그 자리를 살폈다.

닦인 면과 남은 자국 사이에 손톱만 한 틈이 있었다. 윤서는 그 가장자리를 가까이서 살핀 뒤 본 자리를 일지에 남겼다.

*이 묘사로 새 웅크리기 입력·오브젝트·조사 단계를 추가하지 않는다. 몸짓과 표면은 연출 후보다. 기록을 지운 장치, 지워진 내용, 의도는 확인되지 않았다.*

## 6. 귀환과 보고

*세 필수 기록을 모두 조사한 뒤, 플레이어가 자율 귀환해 현재 완료 보고를 하는 경우의 원고다. 중간 귀환에는 아래 별도 문안을 사용한다.*

미나는 세 기록을 겹쳤다. 윤서가 맨 위의 것을 다시 옆으로 옮겼다.

“섞지 마.”

“안 섞어. 자리만 비우는 거야.”

윤서는 손을 거뒀다.

“같은 집이야?”

“위치는 달라.”

“사람도?”

윤서는 종이를 보았다.

“그건 못 봤어.”

미나는 맨 아래 기록을 조금 더 꺼냈다.

“이쪽부터 읽으면 돼?”

“그걸 먼저 봐.”

미나는 세 장의 위쪽을 조금씩 어긋나게 놓았다. 맨 아래에 가려져 있던 확인란이 나왔다.

## 짧은 노출층

이 절은 필수 목표와 현재 관측 범위를 전달하는 문안이다. 긴 산문을 읽지 않아도 세 기록의 역할을 구별할 수 있어야 한다. 일지에 쓰는 사실은 실제로 읽은 기록의 주장에 한정한다.

### 필수 목표

현재 후속 의뢰 `분양 주택 기록 대조`의 세 기록 조사와 귀환 보고를 안내한다. 목표 개수는 현재 기능을 따른다. 청소 흔적을 완료 조건에 포함하지 않는다. 장소 이동과 선택 조사에 별도 타이머를 두지 않는다.

### 부분 귀환

윤서: “아직 남았어.”

미나: “다음에 이어서 보자. 지금까지 본 건 남겨 두고.”

이 대화는 미완료 보고다. 완료·보상·새 의뢰 해금을 일으키지 않는다. 기존 저장에 성공한 진행을 이어 사용한다. 실패한 저장까지 보존됐다고 말하지 않는다.

### 이미 보고한 뒤 재대화

미나: “그 기록은 받았어. 다시 본 데가 있으면 그것만 알려줘.”

반복 보고에 성장 보상을 다시 주지 않는다. 선택 청소 흔적을 나중에 보았으면 추가 관찰로만 다루고 전체 의뢰를 처음 완료한 것처럼 재연출하지 않는다.

### 두 기록을 비교할 때의 일지

**1과 2를 모두 읽은 경우:**

> 현장 확인란이 비어 있는 기록과, 다른 주소의 자료를 사용했다고 적힌 기록을 보았다.

**1과 3을 모두 읽은 경우:**

> 관계 확인은 이전 구성표를 썼고, 프로필에는 새 확인 기록이 없다고 적혀 있다.

**2와 3을 모두 읽은 경우:**

> 다른 주소에서 가져온 이름 항목과 재사용된 가족 구성 설명을 읽었다. 실제 당사자 관계는 미확인이다.

모든 비교를 자동으로 연달아 낭독하지 않는다. 플레이어가 실제로 본 자료를 다시 살필 때 참고할 짧은 층이다. 새로운 기록을 하나 읽었다는 이유로 아직 보지 않은 다른 기록을 아는 문장을 내보내지 않는다.

### 세 기록 확인 뒤의 종합 일지

> 세 기록에서 등록 자료의 재사용, 다른 주소의 자료 적용, 새 확인 없는 최신 표시를 읽었다. 한 집의 오래된 기록만으로 설명하기 어렵다. 실제 가족관계는 확인되지 않았다.

여기서 확인한 것은 제안한 기록의 내용이다. 실제 사람이 다른 주소로 이동했다거나 같은 가족이 복제됐다는 증거가 아니다. 문학 본문에서 남긴 여운과 진행용 일지의 명확한 범위를 따로 둔다.

### 청소 흔적을 본 경우에만 추가

윤서: “닦인 자국은 봤어.”

미나: “뭘 치웠는데?”

윤서: “남은 자국만.”

일지:

> 닦인 자국을 보았다. 무엇이 지워졌는지, 어떤 장치가 작업했는지는 확인하지 못했다.

청소를 보지 않은 플레이에는 위 세 발화와 일지를 넣지 않는다. 본문 6절의 결말은 청소 흔적 없이도 성립한다. VAC-0의 정체나 의도, 특정 사람의 흔적이 사라졌다는 사실을 확정하지 않는다.

## 세 기록의 서로 다른 일

| 기록 | 직접 읽을 수 있는 것 | 달라지는 질문 | 이것만으로 말할 수 없는 것 |
|---|---|---|---|
| 1 확인란 | 이전 구성표와 유효 인증, 작성되지 않은 현장 확인란 | 유효한 인증이 현재 사람의 확인인가? | 실제 가족·생사·잘못된 이름의 주인 |
| 2 적용 위치 | 다른 주소의 자료를 현재 주택에 적용했다고 적힘 | 이 집의 설명은 이 집에서 확인한 자료인가? | 실제 사람의 이동, 같은 가족이라는 결론 |
| 3 최신 | 새 확인 기록 없이 재사용한 설명에 최신 표기가 붙음 | 화면의 최신 표기가 관찰의 최신성도 보장하는가? | 원본 계보 전체, 편집 주체·의도·세계 배후 |

셋을 읽어도 세계의 원인을 새로 알게 되지는 않는다. 대신 첫 집의 기록만 낡았다는 설명으로 닫기 어렵다는 제한된 답을 얻는다. 관계를 직접 확인한 사람의 말이 왜 필요한지 다음 질문이 생긴다.

## 자유 조사 순서 검수

1·2·3의 원고는 각각 다른 기록을 읽었다는 표현을 포함하지 않는다. 두 번째 기록 이후에는 이미 확보한 조합의 비교만 가능하다. 세 기록을 다 보았을 때만 종합 일지와 완료 보고 후보를 사용할 수 있다. 실제 완료·보상 처리는 현행 코드의 조건을 그대로 따른다.

| 조사 순서 | 두 번째까지 가능한 비교 | 세 번째까지 도달하는 범위 |
|---|---|---|
| 1 → 2 → 3 | 빈 현장 확인란과 다른 주소 자료의 적용 | 새 확인 없는 최신 표기까지 관찰. 실제 관계는 미확인 |
| 1 → 3 → 2 | 이전 구성표와 새 확인 없음 | 적용 위치까지 달라 한 집의 오래된 서류만으로 닫기 어려움 |
| 2 → 1 → 3 | 다른 주소 자료와 미작성 현장 확인 | 최신 표기를 직접 확인의 갱신과 구분 |
| 2 → 3 → 1 | 다른 주소 자료와 재사용 설명 | 인증의 유효성이 실제 가족 확인을 대신하지 않음 |
| 3 → 1 → 2 | 새 확인 없는 출력과 이전 구성표 | 자료가 적용된 위치도 다름을 함께 대조 |
| 3 → 2 → 1 | 재사용된 설명과 다른 주소 자료 | 확인란의 공백을 포함한 종합 범위에 도달 |

청소 흔적은 어느 순서 중간에도 선택적으로 볼 수 있다. 본다고 세 기록을 다 본 것이 되지 않는다. 안 본다고 핵심 의뢰·필수 미스터리가 실패하지 않는다.

### 호출 선택과의 연결

L01의 호출 보류/기존 대기 유지가 L02 세 기록의 진실을 결정하지 않는다. 호출은 그 상태대로 기억하되 L02에서 실제로 관찰한 내용과 별도로 보고한다. 호출 보류가 이 집의 사람을 지웠다거나 대기 유지가 가족을 구했다는 새 인과를 만들지 않는다.

## 세 차례 퇴고

완결 초고 → 목소리·subtext 수정 → 문장 퇴고를 실제로 따로 수행했다. 기록·보고·선택 흔적 원고에 더해 짧은 일지와 부분 귀환 문안도 같은 순서로 검토했다.

| 단계 | 발견 | 수정 |
|---|---|---|
| Scene truth | 기록의 공백을 실제 사람의 부재로 단정하는 문장 | ‘현장 확인란 미작성’이라는 기록의 관찰로 좁힘. 생사·가족관계 확정 삭제 |
| Voice + subtext | 윤서와 미나가 같은 방식의 검수 설명을 반복함 | 윤서는 ‘섞지 마’, 미나는 ‘자리만 비우는 거야’로 서로 다른 부탁을 둠. 미나의 행동을 곧바로 악의적 요약으로 해석하지 않음 |
| Line edit | 다른 주소의 이름을 실제 사람의 이동으로 읽게 하는 비약, 최신과 진실을 설명하는 결론 | 불러온 곳과 적용 위치를 왕복하는 시선, 같은 화면의 두 표기로 교체. 마지막 해설을 지우고 가려진 확인란에서 끝냄 |

## 검증 결과와 확인 필요

### 이번에 수행한 편집 검증

6개 순서 × 청소 관측 유무 2 × L01 호출 선택 2 × 필수 기록 관측 수 0·1·2·3의 4단계로 **96개 편집 조건행**을 생성했다. 각 행에서 이미 본 기록 집합을 정하고, 두 기록 비교는 두 항목 모두 관측된 경우에만 허용했다. 종합 보고 후보는 세 기록 관측 뒤, 청소 문안은 청소 관측 뒤에만 허용하도록 일관성을 확인했다.

이것은 원고의 노출 조건을 열거한 작은 논리 모형이다. 실제 게임 상태, 저장 필드, 문장 바인딩, 여섯 동선, 상호작용, 실패 복구를 테스트한 것이 아니다. 이미 완료한 보고 상태와 저장 실패의 실제 처리는 후속 런타임 검증에 남긴다. 96이라는 수는 문학 품질 점수도 아니다.
