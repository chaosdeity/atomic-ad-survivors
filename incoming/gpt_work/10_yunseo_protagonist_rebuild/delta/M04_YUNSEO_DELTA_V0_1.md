# M04 YUNSEO DELTA V0.1

상태: PM 검토용 PATCH PROPOSAL. CLEAN V0.2 미적용.
범위: 윤서만. 병실 환자, 돌봄 담당자, 심사 대리, 미나의 성격 재설계 없음.

## PATCH 1 — V2-058 구출자로 보이는 유혹

PRECHECK
1. WANT: 환자의 작은 창가 요청을 실제로 이루는 사람이 되고 싶다.
2. FEAR: 그 일이 ‘윤서가 데려갔다’는 큰 이야기로 바뀌는 것.
3. RECOGNITION HUNGER: 구출자로 보이는 인정이 싫지만은 않다.
4. OVERREACH: 종료 시점과 외부 돌봄까지 자기 계획으로 넓힘.
5. RETRACTION: 문/물건만 맡고 몸 이동은 담당자에게 돌림.
6. COST: 영웅 역할과 통제감을 내려놓고 기다림.

SCENE:
내가 고른 자리라고 쓰지 마세요.

BEFORE CONTEXT:
심사 대리가 윤서를 밖에서 함께 있을 사람으로 읽고, 환자는 작은 창가 요청만 원한다.

CURRENT YUNSEO:
“제가 데려간 것처럼 쓰지 마세요. 문은 잡을게요. 몸을 옮기는 건 할 줄 몰라서요.”

PROBLEM:
대사만 보면 환자의 ‘내 선택을 대신 쓰지 마’ 문법과 겹친다.

PROPOSED YUNSEO:
현재 대사 유지.
직전 내면 후보: “데려가는 사람처럼 보이는 건, 생각보다 기분이 나쁘지 않았다. 그게 더 문제였다.”
행동 후보: 윤서는 종이에서 자기 쪽을 한 번 보다가 환자 쪽으로 돌려 놓는다.

ACTION CHANGE:
구출자 인정의 작은 쾌감을 실제로 포기.

INTERIORITY CHANGE:
올바른 경계 인식보다 욕망을 먼저 노출.

WHY STILL YUNSEO:
자기 좋은 서사가 타인의 작은 선택을 덮는 순간을 스스로 잘라낸다.

PLAYER-VECTOR COMPATIBILITY:
ATTACHMENT/CONTROL은 구출자 역할 유혹이 커질 수 있고, DELEGATION은 작은 지원 역할로 내려오는 속도가 빠를 수 있다.

## PATCH 2 — V2-023 미나 이름 선사용

PRECHECK
1. WANT: ‘밤에 실제로 누가 있나’라는 질문에 빈손으로 답하고 싶지 않다.
2. FEAR: 받을 사람이 없는 선택지를 권하는 사람이 되는 것.
3. RECOGNITION HUNGER: 자신과 보급소가 실제 답이 되고 싶다.
4. OVERREACH: 미나 동의 전에 이름을 자기 계획에 넣음.
5. RETRACTION: 미나의 장기 역할을 취소하고 오늘 자기 노동만 제시.
6. COST: 자기 밤과 다음 출격 지연.

SCENE:
다른 사람의 이름을 쓰기 전에.

BEFORE CONTEXT:
윤서가 병원에서 미나를 야간 도움 인물처럼 말하려다 멈췄음을 고백한다.

CURRENT YUNSEO:
“네 이름을 먼저 빌렸어. 오늘 앞쪽은 내가 맡아 볼게. 못 하는 건 너를 불러야 하고.”

PROBLEM:
업무 배치가 앞에 보여 미나식 전술처럼 읽힌다.

PROPOSED YUNSEO:
대체 후보:
“네가 맡는다고 내가 먼저 말해 버렸어. 그건 취소할게. 오늘 앞쪽은 내가 볼 수 있어. 혼자 못 하는 건 너를 깨워야 해.”

ACTION CHANGE:
‘이름’이라는 추상어보다 실제로 만든 약속을 먼저 취소하고, 자기 한계를 같이 말함.

INTERIORITY CHANGE:
내면 후보: “미나가 그냥 괜찮다고 해 주면 편할 것 같았다. 그 편함부터 빌리려 했다.”

WHY STILL YUNSEO:
자기 계획이 타인의 역할을 선사용했음을 깨닫고 자기 개입을 줄이며 비용을 자기 밤으로 가져온다.

PLAYER-VECTOR COMPATIBILITY:
CONTROL은 오늘 밤을 더 많이 맡으려 하고, SELF-PRESERVATION은 가능한 시간/업무를 더 좁혀 합의할 수 있다.

## PATCH 3 — V2-057 도움 요청

PRECHECK
1. WANT: 미나를 깨우지 않고 혼자 해내고 싶다.
2. FEAR: 자신이 실제 도움을 줄 수 없는 사람으로 보이는 것.
3. RECOGNITION HUNGER: 필요한 사람이고 싶다.
4. OVERREACH: 몸 이동까지 혼자 시도하려 팔을 뻗음.
5. RETRACTION: 손을 내리고 미나를 깨움.
6. COST: 미나 수면과 자기 체면을 모두 지불.

SCENE:
깨워야 하는 때.

BEFORE CONTEXT:
윤서가 잠깐 졸고, 거주자가 몸 이동 도움을 요청한다.

CURRENT YUNSEO:
“혼자 하면 안 될 것 같아요. 미나 불러올게요.”

PROBLEM:
단독 대사는 일반 돌봄 문장이라 화자 구별이 약함.

PROPOSED YUNSEO:
대사는 그대로 KEEP.
직전 내면 후보를 강화:
“깨우기 싫었다. 미나 때문이 아니라, 깨우지 않고 끝내고 싶은 쪽이 더 컸다.”
윤서는 뻗었던 팔을 완전히 내린 뒤 일어선다.

ACTION CHANGE:
도움 요청을 competence 부족이 아니라 필요해지고 싶은 욕망을 포기하는 행동으로 보이게 함.

INTERIORITY CHANGE:
자기희생을 미화하지 않고 인정 욕구를 드러냄.

WHY STILL YUNSEO:
선 넘은 도움을 실제로 줄이고 필요한 일은 다른 방식으로 계속한다.

PLAYER-VECTOR COMPATIBILITY:
SELF-ERASURE는 더 늦게 도움을 청할 위험, SELF-PRESERVATION은 더 빨리 호출하되 맡은 작은 일을 유지.

## PATCH 4 — 피곤한 유머

PRECHECK
1. WANT: 밤 일을 망치지 않고 끝내고 싶다.
2. FEAR: 자기 피로가 다른 사람 부탁을 틀리게 만드는 것.
3. RECOGNITION HUNGER: 밤 당번으로 쓸 만한 사람이고 싶다.
4. OVERREACH: 쉬지 않고 계속 움직임.
5. RETRACTION: 실수 공개 후 인계를 받음.
6. COST: 출격 지연과 수면.

SCENE:
밤의 첫 번째 일.

BEFORE CONTEXT:
윤서가 요청한 천을 잘못 가져와 두 번 오간다.

CURRENT YUNSEO:
실수 후 바로 다시 간다.

PROBLEM:
피로와 인간적 매력이 공포/노동에 눌린다.

PROPOSED YUNSEO:
짧은 자기 농담 후보:
“오늘 나한테 맡기면 물건이 한 번 더 산책하네.”
즉시 다시 찾으러 간다. 상대에게 웃음을 요구하지 않는다.

ACTION CHANGE:
없음. 업무 결과 동일.

INTERIORITY CHANGE:
피로를 숨기지 않되 자기연민으로 늘이지 않음.

WHY STILL YUNSEO:
관계와 몸에서 나오는 짧은 유머이며 윤리 캐치프레이즈가 아니다.

PLAYER-VECTOR COMPATIBILITY:
ATTACHMENT에서는 상대와 공유한 실수로 남을 수 있고, DISTANCE에서는 혼잣말 수준으로 끝난다.
