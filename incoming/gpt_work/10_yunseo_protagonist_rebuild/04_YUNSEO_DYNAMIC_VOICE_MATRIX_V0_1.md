# 윤서 DYNAMIC VOICE MATRIX V0.1

상태: CANDIDATE. 대사집이 아니라 작가용 생성 규칙.
원칙: 말끝이 아니라 지각, 첫 충동, 틀리는 방식, 수정 행동이 윤서를 만든다.

## BASE

- what she notices: 자기 손/말이 상대의 역할을 먼저 정했는지
- first impulse: 작은 실무를 직접 잡음
- wrong move: 필요한 일을 핑계로 상대 몫까지 정함
- spoken language: 짧고 구체적. 큰 약속보다 지금 할 일을 말함
- interior language: 욕심과 피로가 먼저, 해석은 나중
- humor: 익숙한 사람과 피곤한 받아치기
- anger: 잘못 하나를 짧게 짚고 손이 빨라짐
- fear: 도움이 됐다고 믿는 동안 상대 말이 사라지는 것
- apology: 자기 의도를 설명하기보다 잘못 건드린 부분부터 되돌림
- repair action: 손을 떼고, 필요한 기능은 남기고, 상대의 다음 선택을 기다림

## HOLD

- notices: 답을 잘못 붙일 가능성
- first impulse: 한 번 더 확인
- wrong move: 기다림 비용을 상대에게 떠넘김
- spoken: 질문이 하나 더 붙지만 장황한 검증 강의는 피함
- interior: 조금만 더 알면 된다 / 저 사람은 얼마나 기다렸지
- humor: 늦게 알아듣고 자기 지연을 짧게 웃음
- anger: 서두르게 하는 압력에 말보다 멈춤으로 버팀
- fear: 자기 말이 관계를 먼저 고정
- apology: 늦춘 시간을 인정
- repair: 확인 중에도 물, 문, 통로 같은 현재 일을 맡음

## COMMIT

- notices: 지금 놓치고 있는 사람/시간
- first impulse: 범위를 정해 행동부터 시작
- wrong move: 행동과 역할 결정을 한꺼번에 밀어붙임
- spoken: “지금 내가 할 것”이 앞에 옴
- interior: 돌아와서 물어도 된다 / 또 늦으면 어쩌지
- humor: 일을 벌인 뒤 자기 성급함을 짧게 인정
- anger: 움직임을 막는 말에 즉각 반응
- fear: 행동이 나중에 포괄 약속으로 기록됨
- apology: 내가 먼저 정했다고 인정
- repair: 되돌릴 비용을 직접 내고 상대 선택에 맞춰 경로 변경

## SELF-ERASURE

- notices: 남의 부족한 손과 시간
- first impulse: 자기 몫을 빼고 더 맡음
- wrong move: 피로/부상을 숨겨 더 큰 인계 사고를 만듦
- spoken: 괜찮다는 말을 빨리 함
- interior: 내가 하면 된다 / 지금 깨우면 폐 끼친다
- humor: 몸 비용을 농담으로 축소
- anger: 자기에게 화가 나도 일로 덮음
- fear: 쓸모없는 사람이 되는 것
- apology: “다음엔 더 잘 버틸게”라는 가짜 사과 위험
- repair: 실제 도움 요청과 교대를 받아들이는 것이 핵심

## SELF-PRESERVATION

- notices: 자기 몸/시간도 현장 조건임
- first impulse: 가능한 범위를 먼저 계산
- wrong move: 경계를 지키느라 급한 요청을 놓칠 수 있음
- spoken: 내 시간, 팔, 수면을 구체적으로 말함
- interior: 쉬어야 다시 올 수 있다 / 그래도 저 표정 보기 싫다
- humor: 피곤함을 숨기지 않는 짧은 자조
- anger: 자동 기대에 직접 선을 긋음
- fear: 자기보호가 버림으로 읽힘
- apology: 못 한 일과 거절 권리를 섞지 않음
- repair: 인계 조건을 만들고 맡은 부분은 끝냄

## CONTROL

- notices: 순서가 흐트러지는 지점
- first impulse: 자기가 동선과 순서를 잡음
- wrong move: 보호 명분으로 몸/시간/대답을 대신 정함
- spoken: 짧은 지시가 빨라짐
- interior: 내가 옆에 있으면 덜 틀린다
- humor: 상대 순서를 놀리다 제지받으면 멎음
- anger: 손이 말보다 먼저 나갈 수 있음
- fear: 보지 않는 동안 잘못될 것
- apology: 마음에 안 드는 상대 답도 받아들여야 함
- repair: 자기 순서를 취소하고 물건/통로를 상대 선택에 맞춰 다시 배치

## DELEGATION

- notices: 상대가 실제로 고를 수 있는 조건
- first impulse: 가능한 선택지를 물리적으로 마련
- wrong move: 조건 없이 “네가 골라”라고 떠넘김
- spoken: 가능 범위와 중단 조건을 제시한 뒤 기다림
- interior: 내가 고른 답이 아니어도 따라야 한다
- humor: 자기 예상이 빗나간 것을 웃을 수 있음
- anger: 누군가 상대 답을 가로챌 때 강하게 끊음
- fear: 맡긴 선택의 손실을 못 견딜까 봄
- apology: 방치한 조건부터 채움
- repair: 선택권은 돌려주되 필요한 물건/시간/길은 자기 손으로 마련

## DISTANCE

- notices: 오늘 부탁의 정확한 크기
- first impulse: 범위를 넘지 않음
- wrong move: 관계를 만들지 않으려 필요한 관심까지 줄임
- spoken: 미래 약속을 적게 함
- interior: 여기까지면 됐다 / 더 묻지 않아도 되나
- humor: 사적 놀림보다 상황 반응
- anger: 친밀함을 이유로 한 의무 강요를 끊음
- fear: 아무도 다음에 자신을 찾지 않을 것
- apology: 맡은 일은 복구하지만 관계 회복을 강요하지 않음
- repair: 떠나기 전 후속 책임의 인계만 분명히 함

## ATTACHMENT

- notices: 그 사람이 지난번 고른 작은 것
- first impulse: 부탁하기 전에 다시 옴
- wrong move: 애착을 이유로 더 많이 대신 정함
- spoken: 지난 선택/다음 만남을 구체적으로 언급
- interior: 내가 아니어도 괜찮았을까 / 다른 사람에게도 저 부탁을 했을까
- humor: 공유한 실수나 습관에서 나옴
- anger: 그 사람을 막는 일에 과하게 빨리 개입
- fear: 자신이 교체되거나 필요 없어짐
- apology: 용서받으려 오래 머무르는 위험
- repair: 상대가 더는 자신을 원하지 않는 선택도 실제로 존중

## invariant 검증

어떤 상태에서도 다음 중 최소 둘이 행동으로 보여야 한다.

- 자기 개입이 타인의 선택을 덮을 수 있다는 위험
- 현장에서 직접 움직이는 성향
- 자기 방식의 실패 가능성
- 거절 뒤 실제 개입 축소
- 필요한 일을 버리지 않는 책임
- 후속 비용을 자기 쪽으로 가져오는 수정

특정 문구의 반복으로 통과 처리하지 않는다.
