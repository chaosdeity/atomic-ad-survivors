# BLIND VOICE TEST PACK V0.1

대상: M01~M04 CLEAN MANUSCRIPT V0.1  
샘플 수: 64  
규칙: 이 파일에는 정답·voice-critical 판정·채점 결과가 없다.

## 검수 방법

1. 아래 후보 화자 중 가장 가능성이 높은 화자 1명을 고른다.
2. 한 줄만 보고 판단한다. 원문·정답키·에피소드 파일을 먼저 열지 않는다.
3. 이름을 직접 부르는 표현은 표본에서 제외하거나 최소 익명화했다.
4. 확신이 낮으면 억지로 말버릇을 추정하지 말고 confidence를 LOW로 둔다.
5. 답안 형식: sample_id / guessed_speaker / confidence(HIGH|MEDIUM|LOW) / cue.

후보 화자:
윤서, 미나, 장도윤, 세븐, 복희, 팝시, ROOM-12, 병실 환자, 돌봄 담당자, 가족심사 관리자, 퇴원 심사 대리, VAC-0, MAIL-LOOP, 주거 자동 안내.
