# M01 IMPLEMENTATION SCRIPT V0.1

기준 원고: M01 — 문은 먼저 열렸다 CLEAN V0.1  
목적: CLEAN의 사건·대사·내면 의미를 구현 단위로 분리한다. 신규 저장값·보상·지역·정사를 확정하지 않는다.

## BEAT 01 — 빈 것을 놓는 자리

SCENE: 허브 출발 전  
LOCATION: 침묵 보급소 카운터

ACTION:
- 미나가 빈 붕대 칸과 뜯긴 포장을 확인한다.
- 도윤은 윤서의 스캐너 손잡이를 시험시키고 자기 다친 손은 뒤로 미룬다.
- 윤서는 도윤 손과 자기 장비 사이에서 시선을 오간다.
- 미나가 M01 조사 항목 두 개를 종이에 지정한다.
- 윤서는 메모에 ‘문’, ‘키트’를 적고 출발한다.

DIALOGUE:
- 도윤: “이쪽으로 잡아 봐. 끝까지 힘주지 말고.”
- 미나: “이거 썼으면 여기 놔. 안쪽 칸 말고.”
- 윤서: “없을 수도 있어.”
- 미나: “그러면 없다고 해. 찾기 전에 있는 걸로 세진 않을 테니까.”
- 미나: “이 둘은 읽어 와. 물건을 꺼낼 수 있는지도 직접 보고.”
- 윤서: “네가 먼저 놓는 연습 좀 해.”

INTERIORITY_OPTIONAL:
- 윤서: 자기 장비 상태를 먼저 묻고 싶은 마음을 삼킨다.

MACHINE: 없음.

RECORD:
- 출발 메모: 우편함 수령 기록 / 세대 인증 기록 / 문 / 키트.

UI:
- 기존 출격·이동 UI 사용.
- 별도 신규 튜토리얼 팝업 금지.

STATE_DEPENDENCY:
- M01 진입 가능 상태.
- 스캐너 사용 가능.
- 부상·붕대는 연출 후보이며 강제 HP 조건으로 만들지 않는다.

IMPLEMENTATION_NOTE:
- 빈 포장은 ‘재고 없음’의 시각 단서다. 신규 인벤토리 아이템으로 확정하지 않는다.

## BEAT 02 — 대답보다 먼저 열린 문

SCENE: 첫 주택 진입  
LOCATION: 침묵 가장자리 주택 현관

ACTION:
- 윤서가 손을 들기 전에 문이 열린다.
- 현관 오른쪽 키트에서 미개봉 붕대 봉투 둘을 확인하고 가방에 넣는다.
- 의자에 잠깐 체중을 실었다가 떼고, 우편함 호출을 듣는다.
- 윤서가 사람을 부르지만 응답은 없다.

DIALOGUE:
- 윤서: “계세요?”

INTERIORITY_OPTIONAL:
- 윤서: “오늘은 천을 풀 수 있겠다.”

MACHINE:
- 주거 자동 안내: “응급 키트는 현관 오른쪽에 있습니다. 앉아서 이용하실 수 있습니다.”
- MAIL-LOOP: “수령인을 기다리고 있습니다. 안내에 따라 확인해 주세요.”

RECORD: 없음.

UI:
- 키트 조사 상호작용.
- 우편함 조사 상호작용.

STATE_DEPENDENCY:
- 키트에서 확인 가능한 실제 물건이 있어야 한다.
- 봉투 둘은 원고 연출 수량이며 고정 드롭 수량으로 잠그지 않는다.

IMPLEMENTATION_NOTE:
- 기계 음성은 감정 해석을 하지 않는다.
- 문이 열린 사실과 사람이 있다는 사실을 연결하지 않는다.

## BEAT 03 — 끝났다고 적힌 일

SCENE: 기록 조사  
LOCATION: 주택 내부 / 우편함 / 세대 기록 벽면

ACTION:
- 윤서가 우편함 기록과 세대 기록을 순서와 무관하게 읽는다.
- ‘빈집’이라 쓰려다 멈추고 관찰 범위만 메모한다.
- 광고 장치가 가동되며 유한 전투가 시작된다.
- 윤서가 벽 덮개에 팔을 스쳐 출혈한다.

DIALOGUE: 없음.

INTERIORITY_OPTIONAL:
- 윤서: “대답은 없었다. 그건 쓸 수 있다.”

MACHINE:
- MAIL-LOOP: “수령인을 기다리고 있습니다.”

RECORD:
- 우편함: 수령 절차 완료 / 세대 구성표 참조 / 당사자 수령 확인 별도 기록 없음.
- 주택: 세대 인증 유효 / 이전 구성표 사용 / 현장 대조 미기재 / 다른 주택 기록 참조.
- 윤서 메모: 문 선개방 / 미개봉 봉투 둘 / 응답 없음 / 기록 참조 관계.

UI:
- 조사 완료 표시는 ‘기록을 읽음’ 범위만 표현한다.
- 생사·거주자 확인 완료 표시 금지.

STATE_DEPENDENCY:
- 장소 귀속 유한 위협.
- 수동 유지 공격과 이동 사용.

IMPLEMENTATION_NOTE:
- ‘완료’ 텍스트를 사람의 수령 완료로 해석하는 연출 금지.

## BEAT 04 — 가방을 열지 않는 동안

SCENE: 전투 중 부상 선택  
LOCATION: 키트 옆 낮은 벽 / 의자 주변

ACTION:
- 윤서는 부상을 확인하고도 붕대를 쓰지 않으려 한다.
- 피가 손잡이에 묻어 스캐너를 놓칠 뻔한다.
- 의자를 발로 밀고, 결국 봉투 하나를 열어 자기 팔에 쓴다.
- 빈 포장은 가방 바깥, 미개봉 하나는 안쪽에 남긴다.

DIALOGUE: 없음.

INTERIORITY_OPTIONAL:
- “얼마 안 남았다. 돌아가서 해도 된다.”
- “두 개 가져간다고 말한 적은 없다.”

MACHINE:
- 주거 자동 안내 반복: “응급 키트는 현관 오른쪽에 있습니다. 앉아서 이용하실 수 있습니다.”

RECORD: 없음.

UI:
- 붕대 사용이 실제 회복 시스템과 연결되는지는 별도 확인.
- 원고 때문에 강제 아이템 소비 규칙을 신설하지 않는다.

STATE_DEPENDENCY:
- 부상 연출이 존재할 경우 현재 전투 행동과 시각적으로 연결.

IMPLEMENTATION_NOTE:
- 핵심은 ‘남에게 가져갈 물건을 자기 귀환에 사용’한 선택이다.
- 의자 자체를 악성 오브젝트로 만들지 않는다.

## BEAT 05 — 놓았다가 다시 잡기

SCENE: 남은 위협 제거  
LOCATION: 현관 전투 구역

ACTION:
- 윤서가 손잡이를 닦고 이동 후 정지한 뒤 공격한다.
- 방해되던 의자를 벽 쪽으로 옮겨 전투 공간을 확보한다.
- 오래 누르지 않고 손을 풀었다 다시 잡는다.
- 마지막 광고 장치가 꺼진다.

DIALOGUE: 없음.

INTERIORITY_OPTIONAL: 없음.

MACHINE: 없음.

RECORD: 없음.

UI:
- 기존 공격 입력 피드백만 사용.

STATE_DEPENDENCY:
- 장치가 유한하게 제거되어야 한다.

IMPLEMENTATION_NOTE:
- 신규 보스 패턴이나 강제 피해를 추가하지 않는다.

## BEAT 06 — 편지는 남겨 두고

SCENE: 우편 선택  
LOCATION: 우편함

ACTION:
- 윤서가 우편함을 흔들다 손을 놓는다.
- 선택 화면을 연다.
- 기본 CLEAN 경로에서는 ‘안내 멈추기’를 선택한다.
- 벨은 멎고 편지와 보관은 유지된다.

DIALOGUE: 없음.

INTERIORITY_OPTIONAL: 없음.

MACHINE:
- 선택 후: “반복 안내를 중지합니다. 보관 중인 우편은 유지됩니다.”

RECORD: 없음.

UI:
- 선택 항목: 안내 멈추기 / 기다리는 안내 유지.
- 기록 삭제나 가족 판정 버튼 금지.

STATE_DEPENDENCY:
- 기존 우편 선택 의미를 보존.
- 어느 선택도 사람의 생사·가족·구출 결과를 만들지 않는다.

IMPLEMENTATION_NOTE:
- CLEAN은 안내 중단 경로를 대표 본문으로 사용한다.
- 대기 유지 분기는 기존 의미 범위에서 별도 바인딩 가능.

## BEAT 07 — 오늘 본 데까지

SCENE: 자율 귀환  
LOCATION: 귀환 지점

ACTION:
- 윤서가 메모와 가방을 확인한다.
- 미개봉 봉투 하나, 사용한 포장 하나, 자기 팔의 붕대를 확인한다.
- 직접 귀환을 선택한다.

DIALOGUE: 없음.

INTERIORITY_OPTIONAL: 없음.

MACHINE: 없음.

RECORD: 없음.

UI:
- 기존 자율 귀환 UI.

STATE_DEPENDENCY:
- 부분 조사 상태에서도 귀환 가능.
- 미완료를 실패 엔딩으로 만들지 않는다.

IMPLEMENTATION_NOTE:
- 이미 얻은 보상·진행의 중복 지급 금지.

## BEAT 08 — 하나는 여기, 하나는 팔에

SCENE: 허브 보고와 손일  
LOCATION: 침묵 보급소

ACTION:
- 윤서는 새 봉투 하나만 꺼내고 자신의 부상을 보여준다.
- 도윤은 장비 원인을 묻고, 미나는 두 사람의 손을 먼저 보게 한다.
- 윤서는 쓴 몫과 남은 몫을 분리해 보고한다.
- 우편·세대 기록의 확인 범위를 말한다.
- 윤서가 도윤의 기존 천을 풀고 새 붕대 사용을 돕는다.
- 미나는 식사를 계속한다.
- 도윤은 빈 포장을 공구 밑이 아니라 보이는 곳에 둔다.

DIALOGUE:
- 미나: “가방 내려. 팔 먼저 보여.”
- 도윤: “돌릴 때가 아니라?”
- 윤서: “놓쳤다가 다시 잡을 때.”
- 미나: “뜯은 건 이쪽.”
- 윤서: “두 개 있었어. 이건 내가 썼어.”
- 미나: “응. 새것은 하나.”
- 윤서: “남은 건 못 봤어. 내가 꺼낸 둘만 봤어.”
- 윤서: “멈췄어. 편지는 그대로 뒀고.”
- 윤서: “잠깐 손 놔.”
- 도윤: “그걸 잘했다고 하진 말자.”

INTERIORITY_OPTIONAL:
- 윤서: “설명은 안 물었네.”

MACHINE: 없음.

RECORD:
- 미나 귀환 메모: 새 봉투 하나 / 윤서 현장 사용 하나 / 이후 재고 미확인 / 사람 응답·생사 미확인 / 참조 관계 후속 / 우편 보관 유지.

UI:
- 보고 UI가 있다면 확인 범위를 그대로 표시.
- ‘거주자 없음’ 같은 과도한 결론 금지.

STATE_DEPENDENCY:
- 우편 선택 결과에 따라 마지막 기록 한 줄만 달라질 수 있다.

IMPLEMENTATION_NOTE:
- 손일은 허브 감정선 연출이다. 신규 노동 미니게임으로 확정하지 않는다.

## BEAT 09 — 다른 집의 제목

SCENE: 다음 조사 질문 형성  
LOCATION: 침묵 보급소

ACTION:
- 윤서가 다른 주택 자료 참조 줄에 표시한다.
- 미나는 자료를 쌓아두는 것만으로 끝내지 말라고 요구한다.
- 윤서는 읽은 곳을 표시해 오겠다고 답한다.
- 빈 포장은 폐기 쪽으로, 메모는 가방 안으로 옮긴다.

DIALOGUE:
- 윤서: “다음엔 이쪽을 볼게.”
- 미나: “종이만 쌓아 놓고 가면 안 돼.”
- 윤서: “읽은 데 표시해서 가져올게.”

INTERIORITY_OPTIONAL: 없음.

MACHINE: 없음.

RECORD: 없음.

UI: 다음 조사 목적 표시 후보.

STATE_DEPENDENCY:
- M02 진입 조건은 기존 진행을 따른다.

IMPLEMENTATION_NOTE:
- M05 이후 신규 사건·예고를 추가하지 않는다.
