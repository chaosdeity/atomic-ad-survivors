# M04 IMPLEMENTATION SCRIPT V0.1

기준 원고: M04 — 퇴원 다음 날의 밤 CLEAN V0.1  
목적: 병동의 작은 요청, 퇴원 심사 대리의 유효한 반박, 보급소 야간 노동과 아침 인계를 구현 단위로 분리한다. 의료 절차를 새로 규정하지 않는다.

## BEAT 01 — 축하가 끝나는 데까지

SCENE: 병원 첫 접점  
LOCATION: 접수 홀 / 퇴원 안내 출력대

ACTION:
- 출력 완료 음악과 축하 문구가 먼저 나온다.
- 환자는 윤서에게 “뒤도 들어요”라고 막는다.
- 축하 뒤 실제로는 별도 확인이 필요하다는 안내가 이어진다.
- 환자는 자기 출력물을 직접 쥐고 윤서에게 읽게 한다.
- 환자 곁 돌봄 담당자가 병동 복귀를 준비하고 윤서는 문만 잡는다.

DIALOGUE:
- 윤서: “나가시는 거예요?”
- 환자: “아직 안 끝났어요. 뒤도 들어요.”
- 환자: “그다음에 기다리라는 말이 나와요.”
- 환자: “이건 제가 들게요.”
- 환자: “읽어 봐요. 박수는 듣지 말고.”

INTERIORITY_OPTIONAL: 없음.

MACHINE:
- “안내 출력이 완료되었습니다. 새로운 시작을 응원합니다.”
- “퇴원 가능 여부는 별도 확인이 필요합니다. 현재 머무시는 곳에서 다음 안내를 기다려 주세요.”

RECORD:
- 퇴원 후 도움 제공자와 인계 범위 미확인.
- 현재 필요한 도움 병동에서 별도 확인.
- 최종 안내는 퇴원 불가 병동 심사 창구.

UI:
- 축하 출력과 실제 심사 상태를 같은 완료 배지로 묶지 않는다.

STATE_DEPENDENCY:
- M03 뒤 병원 확인 목적.
- 환자는 전면 퇴원 상태가 아니다.

IMPLEMENTATION_NOTE:
- 본명·성별·진단·약물·수치 신규 확정 금지.

## BEAT 02 — 침대 밑에 있던 컵

SCENE: 병실의 생활 물건과 작은 요청  
LOCATION: 병실

ACTION:
- 돌봄 담당자가 침대 주변을 비우며 바구니를 꺼낸다.
- 환자는 컵이 사라질까 걱정하고 보이는 곳에 두라고 요구한다.
- 환자는 창가에 잠깐 앉고 싶다고 말한다.
- 윤서가 도움을 자청하려 하자 환자가 컵만 드는 것으로는 부족하다고 막는다.
- 담당자가 요청의 크기를 다시 묻고 ‘잠깐 창가’라는 범위를 확인한다.
- 윤서는 마지막에 컵 위치를 먼저 묻는다.

DIALOGUE:
- 환자: “컵은 버리지 마세요.”
- 담당자: “버리려는 게 아니에요. 바닥에 두면 닦을 수가 없어요.”
- 환자: “네. 안쪽 말고 내가 보이는 데 놔요.”
- 담당자: “이쪽 길은 남겨야 해요.”
- 환자: “그럼 창문 쪽에서 들고 있을게요.”
- 담당자: “이동할 때 도움이 필요해요.”
- 환자: “컵만 들 줄 알아도 되는 게 아니에요.”
- 담당자: “잠깐 앉아 계시려는 거죠?”
- 환자: “네. 나가는 얘기만 하면 다 퇴원 얘기가 되니까.”

INTERIORITY_OPTIONAL: 없음.

MACHINE: 없음.

RECORD: 없음.

UI:
- 창가 요청을 ‘퇴원 선택’으로 표시하지 않는다.

STATE_DEPENDENCY:
- 현장 담당자의 도움 필요.

IMPLEMENTATION_NOTE:
- 컵은 비극적 유품이 아니라 현재 쓰는 생활물건이다.

## BEAT 03 — 밤에는 누가 있습니까

SCENE: 심사 대리 직접 대면  
LOCATION: 퇴원 불가 병동 심사 창구

ACTION:
- 심사 대리가 외부 자리와 야간 도움을 구체적으로 묻는다.
- 윤서가 미나 이름을 동의 없이 말하려다가 질문에 막힌다.
- 대리는 빈 침구만으로는 실제 돌봄이 되지 않는다고 지적한다.
- 환자는 자기 요청이 병원 밖 퇴원이 아니라 병동 창가라는 점을 직접 말한다.

DIALOGUE:
- 대리: “밖에서 함께 있을 분입니까?”
- 윤서: “보급소에 접어 둔 침구는 있어요.”
- 대리: “밤에는 누가 있습니까?”
- 윤서: “미나하고, 남는 사람들이 나눠서—”
- 대리: “나눴습니까?”
- 윤서: “아직요.”
- 대리: “그러면 그 이름은 쓰지 마세요.”
- 대리: “빈 침구만으로는 안 됩니다.”
- 환자: “나는 그쪽에서 자겠다고 안 했어요.”
- 환자: “저 창문 앞에 앉고 싶다고 했어요.”
- 환자: “병원 밖 말고요. 저기요.”

INTERIORITY_OPTIONAL: 없음.

MACHINE: 없음.

RECORD: 없음.

UI:
- 심사 대리는 인간 대사 스타일.
- HP·보스전 UI 금지.

STATE_DEPENDENCY:
- 환자 요청은 창가 이동.
- 병원 밖 야간 돌봄은 미확인.

IMPLEMENTATION_NOTE:
- 대리의 질문 일부는 타당해야 한다. 악당 강의로 바꾸지 않는다.

## BEAT 04 — 내가 고른 자리라고 쓰지 마세요

SCENE: 요청 범위 재협상  
LOCATION: 심사 창구

ACTION:
- 윤서가 환자의 체류 시간을 대신 정하려다가 제지당한다.
- 돌봄 담당자가 식사 도움 뒤 잠깐 창가까지 동행 가능한 범위를 말한다.
- 환자가 지금이 아닌 담당자 가능 시간 뒤로 선택을 바꾼다.
- 윤서는 자기 역할을 문과 바구니로 한정하고 몸 이동을 맡지 않는다.
- 대리가 이번 요청 범위를 문서화하고 환자가 자기 요청 주체를 명시해 달라고 요구한다.

DIALOGUE:
- 윤서: “잠깐 앉는 거라면 제가 끝날 때까지—”
- 환자: “언제 끝나는지는 나한테도 물어요.”
- 환자: “얼마나 있을 수 있는지 말을 해 주면 되잖아요.”
- 담당자: “식사 도움을 끝내고 나면 잠깐 같이 갈 수 있어요.”
- 환자: “그럼 지금 말고, 그 뒤에 갈게요.”
- 윤서: “저는 문하고 바구니를 맡을게요. 몸을 옮기는 건 제가 할 줄 몰라요.”
- 대리: “그 범위로만 하십시오.”
- 환자: “내가 저기 앉겠다고 한 것도 써 줘요. 이 사람이 골라 준 자리처럼 쓰지 말고.”

INTERIORITY_OPTIONAL:
- 윤서: “나는 데려가겠다고도 못 했는데, 벌써 돌아올 때를 정하고 있었네.”

MACHINE: 없음.

RECORD:
- 요청: 병동 안 창가 잠시 앉기.
- 이동·필요 도움: 현장 담당자 기존 범위.
- 방문자: 문·소지품만.
- 병원 밖 밤 돌봄·전면 퇴원은 미포함.

UI:
- 합의 범위 표시가 있다면 ‘병동 내 짧은 이동’만.

STATE_DEPENDENCY:
- 담당자 지원 가능 시점.
- 환자 현재 의사 재확인.

IMPLEMENTATION_NOTE:
- 의료 이동 방법을 게임 규칙으로 상세화하지 않는다.

## BEAT 05 — 창이 보이는 동안

SCENE: 실제 작은 요청 수행  
LOCATION: 병실 → 병동 창가

ACTION:
- 담당자가 다른 환자 식사 도움을 끝낼 때까지 기다린다.
- 윤서는 바구니를 들었다 내렸다 하며 기다리지만 담당자 대신 개입하지 않는다.
- 환자가 현재도 창가로 갈지 다시 확인한다.
- 담당자가 이동을 돕고 윤서는 문을 잡는다.
- 환자가 창가에 앉아 컵을 받고 윤서에게 시야를 가리지 말라고 한다.
- 호출이 오자 담당자는 복귀 필요를 알린다.
- 환자가 조금 더 있기를 원하지만 컵을 먼저 맡기고 복귀한다.

DIALOGUE:
- 환자: “저쪽 끝나면 온다고 했어요.”
- 환자: “그러니까 그 얼굴 하지 말아요. 나 때문에 늦는 것 같잖아.”
- 환자: “조금 옆으로 가 줄래요?”
- 윤서: “어느 쪽으로요?”
- 환자: “그냥 창문 안 가리게.”
- 환자: “조금만 더 있으면 안 돼요?”
- 담당자: “지금은 같이 돌아가야 해요.”
- 환자: “컵부터 가져가요. 쏟을 것 같으니까.”

INTERIORITY_OPTIONAL: 없음.

MACHINE: 없음.

RECORD: 없음.

UI:
- 창가 체류는 짧은 장면 결과.
- 전면 퇴원 플래그 변경 금지.

STATE_DEPENDENCY:
- 담당자 동행.
- 환자 의사 확인.

IMPLEMENTATION_NOTE:
- 작은 요청이 실제로 성취되어야 한다.

## BEAT 06 — 돌아갈 곳을 고르는 말

SCENE: 병실 복귀와 기록 정리  
LOCATION: 병실 / 심사 창구 인접

ACTION:
- 환자가 침대로 돌아온다.
- 윤서는 컵을 놓기 전 위치를 묻고 손잡이를 돌려 준다.
- 환자는 ‘병동 도움 유지’와 ‘창가에 다녀옴’을 둘 다 기록하라고 한다.
- 대리는 병원 밖 밤 돌봄이 확인되면 다시 이야기할 수 있다고 말한다.
- 윤서는 환자의 이름 없이 오늘 부탁만 기록해 가기로 한다.

DIALOGUE:
- 윤서: “여기 둘까요?”
- 환자: “네. 손잡이는 이쪽으로.”
- 환자: “갔다 왔어요.”
- 환자: “네. 창가도 다녀왔고요. 둘 다 써요.”
- 대리: “밖에서 밤을 맡을 분이 확인되면 다시 얘기할 수 있습니다.”
- 윤서: “알아봤다고만 말하진 않을게요.”
- 환자: “내가 어디서 자고 싶은지도 그때 물어요.”
- 윤서: “오늘 한 부탁만 적어 가도 돼요?”
- 환자: “이름은 안 적어도 되잖아요.”

INTERIORITY_OPTIONAL: 없음.

MACHINE: 없음.

RECORD:
- 기존 심사 항목은 유지.
- 병동 내 창가 이동 완료와 도움 유지 둘 다 기록.

UI:
- 퇴원 상태를 완료로 바꾸지 않는다.

STATE_DEPENDENCY:
- 병동 내 요청 완료.

IMPLEMENTATION_NOTE:
- 당사자의 이름을 신규 고정 데이터로 만들지 않는다.

## BEAT 07 — 다른 사람의 이름을 쓰기 전에

SCENE: 허브 귀환과 미나와의 충돌  
LOCATION: 침묵 보급소

ACTION:
- 윤서가 병동 결과를 보고한다.
- 동의 없이 미나 이름을 야간 돌봄 후보로 말하려 했다고 인정한다.
- 미나는 오늘 밤 실제 앞쪽 침상 업무를 설명한다.
- 윤서는 이번 밤 앞쪽을 맡겠다고 하고 할 수 있는 일을 구체적으로 한정한다.
- 두 사람이 침상마다 필요한 일과 끝난 일을 직접 확인한다.
- 미나는 뒤쪽 호출로 가며 윤서에게 한 요청을 맡긴다.

DIALOGUE:
- 미나: “거기서 데려오기로 했어?”
- 윤서: “아니. 네 이름은 쓰지 않았어.”
- 미나: “나한테 묻기 전에?”
- 윤서: “응.”
- 윤서: “앞쪽은 내가 있을게. 오늘 밤.”
- 미나: “무슨 일까지 할 건데?”
- 윤서: “부르면 가서 뭐가 필요한지 듣고, 물하고 물건 가져다주는 것. 나 혼자 못 하면 너 부르고.”
- 미나: “몸 옮기는 일은 혼자 하지 마. 조용하다고 끝난 걸로 적지 말고.”
- 미나: “이쪽 먼저 봐 줘. 나 저기 갔다 올게.”

INTERIORITY_OPTIONAL: 없음.

MACHINE: 없음.

RECORD:
- 병원 방문 짧은 메모.
- 보급소 야간 기록 시작.

UI:
- 신규 야간 미니게임 강제 금지.

STATE_DEPENDENCY:
- 윤서 자발적 귀환 후 허브 장면.
- 미나 동의 없는 장기 돌봄 약속 없음.

IMPLEMENTATION_NOTE:
- 병동 환자와 보급소 거주자는 다른 사람이다.

## BEAT 08 — 밤의 첫 번째 일

SCENE: 실제 야간 노동  
LOCATION: 보급소 앞쪽 침상

ACTION:
- 윤서가 씻은 컵을 안쪽에 두고 ‘물 전달 완료’라고 기록한다.
- 거주자가 손이 닿지 않는다고 다시 부른다.
- 윤서는 컵을 가까이 옮기고 손잡이 방향까지 확인한다.
- 미나가 쉬러 간 뒤 윤서는 물건 찾기, 조명 조정 등 작은 부탁을 처리한다.
- 잘못된 천을 가져왔다가 다시 찾고, 전체 불을 끄려다 다른 사람 요구와 충돌해 위치 조정으로 해결한다.
- 윤서 자기 물컵은 그대로 남는다.

DIALOGUE:
- 윤서: “물은 놓아드렸어요.”
- 거주자: “알아요. 저기 있잖아요.”
- 윤서: “여기면 돼요?”
- 거주자: “네. 손잡이도.”
- 윤서: “여긴 내가 듣고 있을게. 먼저 자.”
- 미나: “못 하겠으면 불러.”

INTERIORITY_OPTIONAL: 없음.

MACHINE: 없음.

RECORD:
- ‘물 가져다줌’ 뒤 ‘손에 닿는 위치로 수정’ 추가 기록.

UI:
- 요청 완료를 단일 물건 배치만으로 자동 처리하지 않는다.

STATE_DEPENDENCY:
- 미나 휴식 중.
- 윤서 혼자 할 수 없는 도움은 후속 호출 가능.

IMPLEMENTATION_NOTE:
- 실제 노동의 반복과 실수를 보여 주되 신규 상시 시스템으로 잠그지 않는다.

## BEAT 09 — 깨워야 하는 때

SCENE: 한계 인정  
LOCATION: 보급소 야간 침상

ACTION:
- 윤서가 잠깐 졸아 호출 횟수를 확인하지 못한다.
- 몸을 옮기는 도움이 필요하다는 요청에 혼자 손을 뻗었다가 멈춘다.
- 윤서가 미나를 깨우겠다고 말한다.
- 미나도 컵 위치 인계를 말하지 않고 떠난 실수를 인정한다.
- 두 사람이 당사자에게 도움 방식을 물어 함께 처리한다.
- 끝난 부탁과 아침까지 남길 부탁을 다시 나눈다.

DIALOGUE:
- 윤서: “혼자 하면 안 될 것 같아요. 미나 불러올게요.”
- 미나: “이쪽 사람은 안쪽에 두면 손 안 닿아.”
- 윤서: “그 말은 안 하고 갔어.”
- 미나: “응. 내가 말 안 했네. 지금은 탁자부터 비켜 줘.”
- 윤서: “다시 누워. 내가 물어보고 둘게.”
- 미나: “너도 눈 감았으면 말해. 못 들었는지 봐야 하니까.”
- 윤서: “잠깐 잤어. 몇 번 불렀는지는 몰라.”

INTERIORITY_OPTIONAL:
