# M02 IMPLEMENTATION SCRIPT V0.1

기준 원고: M02 — 깨끗한 집에 남은 것 CLEAN V0.1  
목적: CLEAN의 사건을 구현 단위로 분리한다. 세 기록의 기존 조사 슬롯, 자유 순서, 부분 귀환을 보존한다.

## BEAT 01 — 종이를 올리지 말 곳

SCENE: 허브 출발 전  
LOCATION: 침묵 보급소

ACTION:
- 미나가 침구를 옮기며 종이를 올려놓지 말라고 한다.
- 세븐은 어제 자료와 오늘 자료의 출처를 분리한다.
- 미나는 세 기록을 읽어 공통 줄을 표시해 오라고 윤서에게 실제 작업을 맡긴다.
- 윤서는 뒷면에 세 칸을 만들고, 나가기 전 미나와 침구 한쪽을 잠깐 받친다.

DIALOGUE:
- 미나: “거기 말고.”
- 세븐: “누가 작성했는지 먼저 봐야 합니다. 옮겨 적은 문장이라면 별도의 확인으로 셀 수 없습니다.”
- 미나: “읽어서 같은 줄을 표시해 와. 저녁 준비하면서 셋 다 못 읽어.”
- 세븐: “원문과 네가 덧붙인 말을 나누어 줘. 제목만 있어도 다시 찾을 수 있어.”
- 윤서: “이건 다녀와서 같이 옮길게.”

INTERIORITY_OPTIONAL: 없음.

MACHINE: 없음.

RECORD:
- 윤서 비교용 세 칸 메모.

UI:
- 기존 출격 UI.
- 세 조사 목표 표시 가능.

STATE_DEPENDENCY:
- M01 완료 범위에 따라 연결되나 우편 선택 어느 경로에서도 성립.

IMPLEMENTATION_NOTE:
- 침구는 준비 노동의 물건이며 이주 확정 신호가 아니다.

- 윤서는 청소기를 비켜 주고 실제로 안전해진 자리에 발을 디딘다.
- 식탁의 빈 면에 비교 종이를 놓는다.

DIALOGUE:

## BEAT 03 — 세 칸

SCENE: 세 기록 조사  
LOCATION: 주택 내부 세 조사 지점

ACTION:
- 윤서는 세대 확인, 자료 적용 이력, 홈 프로필 출력 이력을 읽는다.
- ‘유효’, ‘최신’ 같은 상태보다 재사용·현장 확인 부재를 기록한다.
- 세 번째 조사 전 광고 장치를 유한 전투로 제거한다.
- 12번 방 가족대표 참조를 확인한다.

DIALOGUE: 없음.

INTERIORITY_OPTIONAL:
- 윤서: “비슷하다. 같다고 적으면 다시 물을 거다. 뭘 보고 같다고 했는지.”

MACHINE:
- 주거 자동 안내: “준비된 가족에게 준비된 집을. 편안한 생활을 약속드립니다.”

RECORD:
- 세대 확인: 이전 구성표 사용 / 현장 확인 미작성.
- 자료 적용: 다른 주소 원자료 / 실거주자 대조 없음.
- 프로필 출력: 저장 생활 프로필 / 새 현장 확인 없음 / 최신 표시 / 12번 방 가족대표 참조.

UI:
- 세 조사 슬롯은 6가지 순서 모두 가능해야 한다.
- 미독 조사 내용은 선출력하지 않는다.

STATE_DEPENDENCY:
- 조사별 완료 상태.
- 부분 귀환 시 읽은 범위만 유지.

IMPLEMENTATION_NOTE:
- 공통 원본 여부와 독립된 거주자 확인 수를 자동 확정하지 않는다.

DIALOGUE:

INTERIORITY_OPTIONAL:

STATE_DEPENDENCY:

IMPLEMENTATION_NOTE:

## BEAT 08 — 종이 셋과 사람 수

SCENE: 허브 보고  
LOCATION: 침묵 보급소

ACTION:
- 세븐이 원기록 손상인지 묻고 윤서는 보조 메모 손상이라고 정정한다.
- 윤서가 세 기록의 재사용 흔적을 설명한다.
- 세븐은 공통 원본도 독립 확인 셋도 확정하지 않는다.
- 미나는 다음 장소를 묻고 12번 방으로 이어진다.
- 미나와 윤서는 침구를 함께 옮긴다.
- 복희는 기존 보관 묶음을 펼치지 않고 앞쪽으로 옮긴다.
- 세븐이 대조 메모를 수정한다.

DIALOGUE:
- 세븐: “원기록이 손상되었습니까?”
- 윤서: “내 메모야. 원래 건 그대로 있어.”
- 윤서: “거기까진 못 봤어. 그래서 선은 안 이었어.”
- 세븐: “그러면 한 원본이라고 확정하지 않겠습니다.”
- 미나: “그럼 다음엔 어디 봐?”
- 윤서: “모델하우스 근처 12번 방.”
- 세븐: “있다고 적혀 있는 것입니다.”
- 복희: “아니. 찾아갈 사람이 보면 알아보게 앞쪽에.”
- 미나: “다음에는 저기에 놓고 읽어.”
- 윤서: “청소기는 없지?”
- 미나: “내가 있어.”
