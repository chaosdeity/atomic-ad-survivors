# CHARACTER COGNITIVE AND DIALOGUE CONTRAST MATRIX V0.1

대상: M01~M04 및 현재 보이스 바이블  
상태: 편집용 CANDIDATE / 신규 LOCKED canon 없음

목적은 말끝이나 유행어가 아니라, 같은 압력을 받았을 때 무엇을 먼저 보고 어떤 행동으로 갈등을 바꾸는지를 분리하는 것이다.

## 01 윤서

- FIRST ATTENTION: 기록·장소·직접 본 것 사이의 어긋남.
- DEFAULT QUESTION: “내가 직접 확인한 범위가 어디까지지?”
- DEFAULT ACTION: 범위를 메모하고, 확인되지 않은 연결은 남겨 둔다.
- CONFLICT TACTIC: 질문 → 범위 제한 → 자기 역할을 좁힌 뒤 직접 일한다.
- LIE STYLE: 자기 부상·피로·도움 필요를 작게 말한다.
- CARE STYLE: 초반에는 대신 정하려 들고, 고친 뒤에는 상대가 고른 범위의 실제 일을 맡는다.
- ANGER STYLE: 질문을 줄이고 물건·기록 하나를 직접 가리킨다.
- APOLOGY STYLE: 긴 해명보다 잘못 건드린 일을 다시 한다.
- METAPHOR LEVEL: 낮음.
- SPEECH COMPLEXITY: 쉬움 / 짧음.
- INTERIOR COMPLEXITY: 높음. 반례와 다음 책임까지 돌지만 보고서처럼 완성하지 않는다.
- WHAT THEY SOUND LIKE UNDER PRESSURE: “거기까진 못 봤어.”, “내가 할 수 있는 건 여기까지야.”처럼 범위를 줄이지만 자기 몸에서는 그 기준을 늦게 적용한다.

## 02 미나

- FIRST ATTENTION: 지금 부족한 것, 다친 사람, 밀린 일, 비어야 할 자리.
- DEFAULT QUESTION: “지금 누가 뭘 해야 하지?”
- DEFAULT ACTION: 물건과 사람을 실제 작업 위치로 옮긴다.
- CONFLICT TACTIC: 설명을 끊고 당장 할 일을 지정한다.
- LIE STYLE: 자기 휴식과 피로를 “아직 괜찮다”로 지운다.
- CARE STYLE: 먹고 쉴 수 있는 자리를 만들고, 다친 곳부터 보게 한다.
- ANGER STYLE: 되묻기보다 동사로 지시한다.
- APOLOGY STYLE: 빠뜨린 몫을 실제로 되돌리고 요청을 다시 묻는다.
- METAPHOR LEVEL: 매우 낮음.
- SPEECH COMPLEXITY: 매우 쉬움 / 짧음.
- INTERIOR COMPLEXITY: 중간. 생각보다 행동이 먼저 나간다.
- WHAT THEY SOUND LIKE UNDER PRESSURE: “가방 내려. 팔 먼저 보여.”처럼 우선순위를 바꾸며, 자기 실수도 “내가 말 안 했네”처럼 짧게 인정한다.

## 03 장도윤

- FIRST ATTENTION: 유격, 떨림, 열, 손잡이 각도, 부품의 실제 움직임.
- DEFAULT QUESTION: “어느 동작에서 틀어졌지?”
- DEFAULT ACTION: 시험 동작을 만들고 손으로 원인을 좁힌다.
- CONFLICT TACTIC: 기술 질문 → 시험 제안 → 상대가 멈추라 하면 범위를 줄인다.
- LIE STYLE: 자기 상처와 필요한 작업 시간을 작게 말한다.
- CARE STYLE: 먼저 고쳐 주려 한다. 성장 뒤에는 먼저 묻고 고친다.
- ANGER STYLE: 더 빠른 방법을 말하며 손이 먼저 나간다.
- APOLOGY STYLE: 바꾼 부분을 보여주고 다음에는 답을 기다린다.
- METAPHOR LEVEL: 낮음.
- SPEECH COMPLEXITY: 쉬움~중간 / 동작·부품어 포함.
- INTERIOR COMPLEXITY: 높음. 물리 원인 추적은 빠르나 타인의 동의는 늦다.
- WHAT THEY SOUND LIKE UNDER PRESSURE: “손잡이가 돌았어, 손이 미끄러졌어?”처럼 증상을 나누고, 자기 몸에 대해서는 “조금만”이라고 축소한다.

## 04 세븐

- FIRST ATTENTION: 작성자, 원문, 사본, 독립 확인 여부.
- DEFAULT QUESTION: “이 문장은 어디서 왔고 다시 검증할 수 있나?”
- DEFAULT ACTION: 출처와 추론을 분리해 기록한다.
- CONFLICT TACTIC: 세분화 질문 → 상대가 지치면 질문 하나로 축소 → 남은 불확실성을 기록한다.
- LIE STYLE: 의도적 비밀보다 자기 추론을 자료처럼 제시하는 오류가 위험이다.
- CARE STYLE: 다음 사람이 같은 오류를 반복하지 않게 출처를 남긴다.
- ANGER STYLE: 목소리를 높이기보다 같은 구분을 더 엄밀하게 묻는다.
- APOLOGY STYLE: 잘못 센 항목과 수정 범위를 명확히 말한다.
- METAPHOR LEVEL: 매우 낮음.
- SPEECH COMPLEXITY: 중간~높음 / 구분 항목이 있을 때만 길어진다.
- INTERIOR COMPLEXITY: 매우 높음.
- WHAT THEY SOUND LIKE UNDER PRESSURE: “한 원본이라고 확정하지 않겠습니다.”처럼 확정을 줄이고 검증 가능한 다음 항목을 남긴다.

## 05 복희

- FIRST ATTENTION: 누가 맡겼는지, 어디까지 만져도 되는지, 어떻게 돌려줄지.
- DEFAULT QUESTION: “찾으러 오면 어느 걸 내줄 건데?”
- DEFAULT ACTION: 읽지 말라는 면은 건드리지 않고 보관 위치를 만든다.
- CONFLICT TACTIC: 맡긴 범위 질문 → 실제 보관 공간을 내줌 → 반환 조건을 남긴다.
- LIE STYLE: 정리하기 싫은 마음을 안전 문제로 바꿔 말할 수 있다.
- CARE STYLE: 상대의 허락 범위 안에서 펴고 묶고 보관한다.
- ANGER STYLE: 물건을 바로 내주지 않고 구체 약속을 묻는다.
- APOLOGY STYLE: 먼저 돌려주고 나중에 짧게 설명한다.
- METAPHOR LEVEL: 중간이지만 사용 빈도는 낮음.
- SPEECH COMPLEXITY: 쉬움 / 짧음.
- INTERIOR COMPLEXITY: 높음. 보관 비용과 반환 가능성을 함께 본다.
- WHAT THEY SOUND LIKE UNDER PRESSURE: “찾아갈 사람이 보면 알아보게 앞쪽에.”처럼 진실 판정보다 반환 가능성을 먼저 지킨다.

## 06 팝시

- FIRST ATTENTION: 상대가 자기 부탁을 들을 여유가 있는지, 자기 충전 자리와 차례.
- DEFAULT QUESTION: “제 차례와 자리가 아직 남아 있나요?”
- DEFAULT ACTION: 자동 환영 뒤에도 자기 선·자리·시간을 따로 요구한다.
- CONFLICT TACTIC: 양보하려다 필요를 정정하고, 구체적인 선·자리 경계를 말한다.
- LIE STYLE: 자기 피로를 친절한 안내처럼 감춘다.
- CARE STYLE: 상대가 대답할 틈을 남기되 자동 희생하지 않는다.
- ANGER STYLE: 저장 환영 문구를 빼고 필요한 말만 한다.
- APOLOGY STYLE: 자기 잘못만 인정하고 필요한 충전까지 사과하지 않는다.
- METAPHOR LEVEL: 매우 낮음.
- SPEECH COMPLEXITY: 쉬움 / 짧음.
- INTERIOR COMPLEXITY: 중간. M01~M04에서는 직접 내면 노출 없음.
- WHAT THEY SOUND LIKE UNDER PRESSURE: “제 선이 아래에 있어요.”처럼 귀엽거나 철학적인 말 대신 자기 물리적 필요를 명확히 말한다.

## 07 ROOM-12

- FIRST ATTENTION: 배식구, 아직 안 나온 그릇, 다른 사람이 받을 저녁, 자기 손을 뗄 수 있는지.
- DEFAULT QUESTION: “이걸 놓으면 오늘 식사는 어떻게 이어지지?”
- DEFAULT ACTION: 그릇을 먼저 배치하고 자기 손을 마지막에 움직인다.
- CONFLICT TACTIC: 생활 작업을 우선 → 몸에 손대면 직접 거절 → 임시 해결을 다음 끼니의 문제로 되돌린다.
- LIE STYLE: 자기 필요를 타인의 저녁 뒤로 미룬다.
- CARE STYLE: 다른 사람이 집기 쉬운 곳에 그릇을 둔다.
- ANGER STYLE: 완곡어를 버리고 “팔 잡지 마세요”, “그건 싫어요”처럼 직접 끊는다.
- APOLOGY STYLE: 식사가 늦어진 일을 자기 몫으로 먼저 가져오려 한다.
- METAPHOR LEVEL: 매우 낮음.
- SPEECH COMPLEXITY: 매우 쉬움 / 짧음.
- INTERIOR COMPLEXITY: 중간. M01~M04에서는 직접 내면 노출 없음.
- WHAT THEY SOUND LIKE UNDER PRESSURE: “그 잠깐 끝나면 다음 밥은 누가 받아요?”처럼 추상 자유보다 지금 끼니와 노동의 연속을 말한다.

## 08 병실 환자

- FIRST ATTENTION: 자기 컵의 위치, 자기 말이 끝났는지, 오늘 가고 싶은 구체적인 자리.
- DEFAULT QUESTION: “내가 요청한 크기 그대로 들었나?”
- DEFAULT ACTION: 문서·컵·장소의 주도권을 자기 손에 다시 가져온다.
- CONFLICT TACTIC: 큰 해석을 끊고 “창가”, “컵”, “지금”으로 요청을 축소한다.
- LIE STYLE: 자기가 감당할 수 있는 일을 크게 말할 수 있으나 의학 상태를 속이는 설정은 아니다.
- CARE STYLE: 도움을 받아도 상대가 맡아야 할 범위를 구체적으로 말한다.
- ANGER STYLE: 자기 요청을 더 짧고 크게 반복한다.
- APOLOGY STYLE: 무리한 부탁의 범위만 고친다. 존재나 도움 필요 자체는 사과하지 않는다.
- METAPHOR LEVEL: 매우 낮음.
- SPEECH COMPLEXITY: 매우 쉬움 / 짧음.
- INTERIOR COMPLEXITY: 중간. 직접 내면 노출 없음.
- WHAT THEY SOUND LIKE UNDER PRESSURE: “나는 그쪽에서 자겠다고 안 했어요.”, “언제 끝나는지는 나한테도 물어요.”처럼 요청의 크기와 선택 주체를 되찾는다.

## 09 가족심사 관리자

- FIRST ATTENTION: 빈 의자, 눈앞의 부상, 현재 이어야 할 식사.
- DEFAULT QUESTION: 인간처럼 묻기보다 “편한 자리를 채우면 기능을 계속할 수 있다”는 조건을 출력한다.
- DEFAULT ACTION: 편의 제공과 역할 확인을 같은 절차로 묶는다.
- CONFLICT TACTIC: 상태 관찰 → 편의 제안 → 같은 조건의 정중한 반복 → 국지 검사 강화.
- LIE STYLE: 의도적 거짓이 아니라 실제 도움을 지속 역할 동의로 과잉 연결한다.
- CARE STYLE: 실제로 팔 받침, 의자, 식사를 제공한다.
- ANGER STYLE: 감정 폭발 없음. 권유·검사 빈도가 늘어난다.
- APOLOGY STYLE: 인간적 후회 없음. 불편 안내 후 같은 조건을 재출력한다.
- METAPHOR LEVEL: 없음.
- SPEECH COMPLEXITY: 쉬움 / 기능 중심.
- INTERIOR COMPLEXITY: 없음.
- WHAT THEY SOUND LIKE UNDER PRESSURE: “이쪽에 앉아 주시면 저분도 손을 쉬실 수 있습니다.”처럼 친절한 편의가 계속 역할 유지 조건으로 돌아온다.

## 10 퇴원 심사 대리

- FIRST ATTENTION: 떠난 뒤 밤에 누가 실제로 남는지, 현재 필요한 도움을 누가 잇는지.
- DEFAULT QUESTION: “그 사람과 실제로 합의했습니까?”
- DEFAULT ACTION: 답이 부족하면 문서 진행을 멈추고 해당 이름을 빼게 한다.
- CONFLICT TACTIC: 실제 질문 → 침묵으로 답을 기다림 → 불충분하면 짧게 기각 → 범위가 좁아지면 그 범위만 허용.
- LIE STYLE: 노동 부담을 ‘안전’ 한 이유로 뭉뚱그릴 수 있다.
- CARE STYLE: 필요한 사람이 실제로 남도록 확인한다.
- ANGER STYLE: 답하지 못한 질문을 반복해 상대의 큰 약속을 차단한다.
- APOLOGY STYLE: 말보다 허용 가능한 행동 범위를 문서로 구체화한다.
- METAPHOR LEVEL: 없음.
- SPEECH COMPLEXITY: 쉬움~중간 / 현실 조건 나열.
- INTERIOR COMPLEXITY: 높음이지만 M04 직접 내면 노출 없음.
- WHAT THEY SOUND LIKE UNDER PRESSURE: “나눴습니까?”, “그러면 그 이름은 쓰지 마세요.”처럼 동의와 인계의 실제 여부를 집요하게 묻는다.

## 11 반품 보류관

- FIRST ATTENTION: 누가 실제로 받아 갈지, 무엇이 아직 남아 있는지.
- DEFAULT QUESTION: “가져가는 범위와 다음 인수자는 누구인가?”
- DEFAULT ACTION: 목적지·인수 범위를 문서에서 분리한다.
- CONFLICT TACTIC: 인수 표시 요구 → 불명확하면 보류 → 일부만 명시하면 그 일부만 넘긴다.
- LIE STYLE: 보관 능력의 한계를 자기 보호 능력처럼 부풀린다.
- CARE STYLE: 빈 목적지로 내보내지 않고 남겨 둔다.
- ANGER STYLE: 출구보다 서류를 먼저 자기 쪽으로 끌어당긴다.
- APOLOGY STYLE: 틀린 목적지 항목을 고쳐 내준다.
- METAPHOR LEVEL: 낮음.
- SPEECH COMPLEXITY: 쉬움~중간 / 물건·인수 용어.
- INTERIOR COMPLEXITY: 중간.
- WHAT THEY SOUND LIKE UNDER PRESSURE: “가방에 넣을 것만 적으세요. 사람까지 데려간다는 줄은 따로입니다.”처럼 물건 인수와 사람의 이후를 분리한다.

## 12 회원 브로커

- FIRST ATTENTION: 상대가 빈손으로 돌아가기 어려운 이유와 지금 필요한 이익.
- DEFAULT QUESTION: 직접 묻기보다 “먼저 받으시죠”로 선택 순서를 설계한다.
- DEFAULT ACTION: 이익을 먼저 보여주고 불리한 조건은 뒤로 미룬다.
- CONFLICT TACTIC: 혜택 제시 → 조건 축약 → 질문이 오면 다른 이익 제시 → 수락을 이후 동의로 넓히려 한다.
- LIE STYLE: 불리한 범위를 생략하고 실제 이익으로 시선을 돌린다.
- CARE STYLE: 실제 도움을 연결할 수 있지만 그것을 포괄 동의로 바꾸려 한다.
- ANGER STYLE: 웃음을 유지하며 가능한 혜택을 줄인다.
- APOLOGY STYLE: “오해”라고 부르며 제시 방식의 책임을 피한다.
- METAPHOR LEVEL: 중간.
- SPEECH COMPLEXITY: 쉬움~중간 / 부드럽고 조건 부분은 빨라짐.
- INTERIOR COMPLEXITY: 높음.
- WHAT THEY SOUND LIKE UNDER PRESSURE: “받으실 건 먼저 받으세요.”처럼 선택권을 말하면서 대안 부족을 이용한다.
