# M01~M04 캐릭터 대화 전술 지도 V0.1

상태: CANDIDATE / 실제 신규 CLEAN V0.2의 주요 대화 21개. 단어가 아니라 실패 뒤 전술 교체를 본다.

## T01 — M01 출발 전 손잡이

**speaker**: 장도윤

**want**: 증상을 재현해 멀쩡한 부분을 더 깎지 않기

**first tactic**: 손잡이부터 시험시킴

**failure**: 자기 받치는 손이 흔들림을 가림

**second tactic**: 자기 손을 빼고 각도를 남기게 함

**cost**: 자기 수리가 끝났다는 말을 늦춤

**what changed**: 수리 설명보다 다시 보여 줄 조건을 남김

## T02 — M01 빈 포장

**speaker**: 미나

**want**: 오늘 보급을 다른 일보다 먼저 배치

**first tactic**: 쓴 포장을 보이게 하라 지시

**failure**: 아침 보고가 없어 준비가 늦음

**second tactic**: 없으면 바로 돌아오게 하고 다른 손을 남김

**cost**: 이미 비워 둔 시간은 돌아오지 않음

**what changed**: 확정 재고가 아니라 노동 순서를 조정

## T03 — M01 봉투 귀환

**speaker**: 윤서

**want**: 자기 사용을 흉으로 보이지 않게 보고

**first tactic**: 남은 물건부터 내밈

**failure**: 상처와 빈 포장 때문에 자기 몫이 드러남

**second tactic**: 사용 생각에 확인을 놓쳤다고 인정

**cost**: 부상·확인 누락을 자기 말에 포함

**what changed**: 해명 대신 도윤의 천을 풀어 줌

## T04 — M01 돌아와 읽는 시간

**speaker**: 미나 / 윤서

**want**: 보고가 미나에게 잔업으로 남지 않게 하기

**first tactic**: 자료를 가져오라 요구

**failure**: 다시 나가면 읽는 일은 미나 몫

**second tactic**: 함께 읽고 자기 명명이 틀리면 윤서가 고침

**cost**: 윤서의 출발 시간

**what changed**: 다음 조사를 정하며 오늘 약속도 남김

## T05 — M02 침구와 세 기록

**speaker**: 세븐 / 미나

**want**: 출처 독립성 / 지금 비울 손 결정

**first tactic**: 주소 수 경계 / 침구 수 질문

**failure**: 서로 다른 질문을 같은 것으로 답함

**second tactic**: 세븐은 복제 경로로 좁히고 미나는 작업 시간 요구

**cost**: 세븐의 완결된 설명, 미나의 기다림

**what changed**: 증거와 준비 노동의 질문을 분리

## T06 — M02 찢어진 메모

**speaker**: 세븐

**want**: 원기록 손상 여부와 수정 경로 보존

**first tactic**: 원기록 손상이라 먼저 적음

**failure**: 손상된 것은 윤서 보조 메모

**second tactic**: 자기 오기를 지우지 않고 수정 표시

**cost**: 정확한 사람이라는 외관

**what changed**: 본인도 틀리고 수정 흔적을 남김

## T07 — M02 같은 가족

**speaker**: 윤서 / 세븐

**want**: 잘못 붙일 관계 경계 / 문장 출처 대조

**first tactic**: 윤서가 연결선을 보류

**failure**: 보류만으로 어떤 일을 누가 할지 안 정해짐

**second tactic**: 윤서는 다음 사람의 말을 듣고 세븐은 경로를 묶음

**cost**: 윤서의 재방문, 세븐의 대조

**what changed**: 모두가 확인 안 됐다고 끝내는 구조 탈피

## T08 — M02 반환과 동선

**speaker**: 복희 / 미나

**want**: 반환 가능한 보관 / 밤마다 돌아가지 않을 길

**first tactic**: 묶음 앞쪽 배치 / 공간 요구

**failure**: 같은 자리를 두 사람이 다 필요로 함

**second tactic**: 복희 자기 보관 자리를 좁힘, 미나 끈을 안 풀고 옮김

**cost**: 복희 공간, 미나 정리 방식

**what changed**: 보관자의 권한과 일하는 사람의 비용을 함께 남김

## T09 — M03 처음 물은 이주

**speaker**: 윤서 / ROOM-12

**want**: 잘못 적은 역할을 고치기 / 그릇 인계 잇기

**first tactic**: 역할 의사를 먼저 물음 / 일부터 부탁

**failure**: 윤서의 좋은 질문도 배식을 늦춤

**second tactic**: 다음 사람에게 그릇이 가는 동안 기다림

**cost**: 질문하는 사람의 시간

**what changed**: 답변 도구가 아니라 자기 순서를 가진 당사자

## T10 — M03 손과 대표

**speaker**: ROOM-12

**want**: 손 하나 바꾸는 임시 처방을 멈추기

**first tactic**: 손을 떼어 실제 정지를 보여 줌

**failure**: 윤서가 반대 손만 묻음

**second tactic**: 식사 인수 노동이 계속 자신에게 남음을 말함

**cost**: 자기 반복 노동의 노출

**what changed**: 기계 가동과 사람의 노동이 구별됨

## T11 — M03 편안한 대표 자리

**speaker**: 가족심사 관리자 / 윤서

**want**: 자리 채움 / 쉬되 대표로 고정되지 않기

**first tactic**: 편안한 받침과 확인을 함께 제안

**failure**: 다음 끼니 책임이 드러남

**second tactic**: 기계는 권유 반복, 윤서는 쉬고 싶은 마음도 인정하며 거절

**cost**: 윤서는 실제 편안함을 놓침

**what changed**: 기계는 인간적 논쟁 대신 국지 강제로 이동

## T12 — M03 팔을 잡은 보호

**speaker**: 윤서 / ROOM-12

**want**: 빨리 출구로 이동 / 신체와 배식 지키기

**first tactic**: 팔을 잡음 / 짧게 거절

**failure**: 윤서의 보호가 자기 거절과 모순

**second tactic**: 손을 떼고 그릇을 받으며 검사만 중단

**cost**: 늦어진 사격·부상 불편

**what changed**: 말의 정답이 아니라 공격·도움 대상 변경

## T13 — M03 남는 사람

**speaker**: ROOM-12

**want**: 다른 그릇 뒤 자기 저녁도 먹기

**first tactic**: 저녁까지 남겠다고 말함

**failure**: 이주 여부만 물으면 자기 욕구가 누락

**second tactic**: 자기 그릇을 따로 앞에 두게 함

**cost**: 자기 바람을 처음부터 말하지 못한 시간

**what changed**: 오늘의 자기 식사, 영구 역할·외출 부탁과 구분

## T14 — M03 환영 뒤 충전

**speaker**: 팝시

**want**: 실제 자기 충전 차례 확보

**first tactic**: 저장 환영이 먼저 재생

**failure**: 인사가 나와도 선은 눌린 채

**second tactic**: 자기 말로 선을 빼 달라 요청

**cost**: 맞아 주기보다 자기 필요를 앞에 놓음

**what changed**: 윤서가 가방을 들고 팝시가 자리를 확보

## T15 — M03 펴지 않은 침구

**speaker**: 미나 / 윤서

**want**: 불확실한 장래 준비를 오늘 잔업으로 받지 않기

**first tactic**: 누가 언제 오나 물음

**failure**: 재방문 시점 없음

**second tactic**: 지금 그릇 닦는 일을 윤서에게 넘김

**cost**: 윤서의 보고 후 휴식

**what changed**: 보류 통지가 아닌 실제 노동 교환

## T16 — M04 컵과 작은 요청

**speaker**: 환자 / 담당자

**want**: 자기 몸·물건 선택 / 현재 지원 일정

**first tactic**: 컵을 보이게 하라 / 바닥 비우기

**failure**: 물건 이동이 몸 이동 계획으로 확대

**second tactic**: 환자는 먼저 묻게 하고 담당자는 돌아올 때 재확인

**cost**: 환자의 대기, 담당자의 가용 시간

**what changed**: 당사자 선택과 도움 가능 범위가 별개

## T17 — M04 밤의 사람

**speaker**: 퇴원 심사 대리 / 윤서

**want**: 실제 인계 / 도울 곳 알아보기

**first tactic**: 밖에서 자리를 찾나 질문

**failure**: 동의 없는 미나 이름이 먼저 나옴

**second tactic**: 대리는 자기 문서 책임을 방어, 윤서는 이름 선사용 중단

**cost**: 윤서의 능력 부족 노출

**what changed**: 실제 인계의 문제는 맞지만 창가까지 막는 과잉은 남음

## T18 — M04 창가로 요청 축소

**speaker**: 환자 / 윤서 / 대리

**want**: 작은 현재 요청을 실제 실행

**first tactic**: 퇴원 조건으로 응답 / 윤서가 종료 시점 정함

**failure**: 환자가 요청 주체와 크기 정정

**second tactic**: 윤서는 문을 맡고 대리는 퇴원 항목을 빼고 담당 시간 확인

**cost**: 지원 가능 시간만큼 기다림

**what changed**: 전면 퇴원 없이 창가 왕복이 실제 성취

## T19 — M04 잘못 빌린 이름

**speaker**: 윤서 / 미나

**want**: 동의 없는 약속 시도 수정 / 오늘 야간 손 분담

**first tactic**: 서명은 안 했다고 보고

**failure**: 이미 미나 시간을 자기 계획에 쓴 사실

**second tactic**: 윤서가 오늘 일을 맡고 한계를 말함

**cost**: 윤서의 밤·출격 지연

**what changed**: 미나의 장기 동의는 만들어지지 않음

## T20 — M04 깨우고 다시 나누기

**speaker**: 미나 / 윤서

**want**: 놓친 호출을 지금 처리

**first tactic**: 미나가 위치 인계를 했다고 여김

**failure**: 윤서가 듣지 못한 지시를 지적

**second tactic**: 미나 자기 누락 인정, 둘이 현재 남은 일을 순회

**cost**: 두 사람 수면

**what changed**: 항상 옳은 교사/항상 부족한 주인공 구도 탈피

## T21 — M04 아침 인계

**speaker**: 미나 / 윤서

**want**: 계속될 일을 받은 사람이 실제로 받기

**first tactic**: 윤서가 끝을 쓰려 함

**failure**: 새 요청이 아직 옴

**second tactic**: 처리 후 미나가 현장을 다시 확인하고 인계

**cost**: 윤서의 늦어진 출발

**what changed**: 문서의 끝과 사람의 필요 종료는 다름

## 반복 전술 검사

윤서는 M01 자기 사용 축소→고백/손일, M02 명명 보류→질문 변경, M03 강제 보호→손 떼고 표적 변경, M04 자기 능력 과장→인계 요청으로 움직인다. ‘작은 책임’이라는 같은 결론이 있어도 그곳까지 가는 잘못과 실제 비용은 다르다. 세븐은 분해·수정 흔적, 미나는 배치·분담, 복희는 반환 조건·자기 공간, ROOM-12는 노동 인계·자기 몫, 환자는 요청 주체 회수, 대리는 방어·항목 수정으로 끝낸다.

의미를 대사에서 지우고 설명을 지문에 옮긴 것만으로 성공 처리하지 않는다. 상대 응답이나 물건 위치·시간·수행자의 변경이 없는 전술은 구현해도 읽히지 않을 수 있다. 독립 식별 효과는 별도 테스트 전까지 미확인이다.
