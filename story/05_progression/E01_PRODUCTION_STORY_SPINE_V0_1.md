## 1. 결론

E01 production spine은 4층으로 나눈다.

1. CORE MAIN PATH
2. STRONG OPTIONAL
3. RELATIONSHIP OPTIONAL
4. DEEP LORE OPTIONAL

첫 플레이는 모든 33편을 하지 않아도:
- 윤서의 행동 습관이 보이고,
- 다른 사람들이 그 습관을 기억하고,
- M10에서 “좋은 윤서” 편집 공포가 생기고,
- M11에서 실제 떠남이 발생하고,
- M12에서 PLAYER-MADE YUNSEO가 성립해야 한다.

completionist는 plot 정답을 더 얻는 것이 아니라:
- 다른 인물의 독립 WANT,
- 윤서 없는 생활,
- 관계 repair,
- 같은 기록을 다르게 해석하는 사람들,
- M12에서 더 풍부한 사회적 기억
을 얻어야 한다.

## 7. COMPLETIONIST FLOW

Completionist에게는 33편 전부를 순서대로 체크리스트처럼 먹이지 않는다.

권고:
- 한 Main 사이 optional 2편 이상 연속 기본 추천 금지.
- 같은 캐릭터 cluster는 한 번 쉬었다가 재노출.
- provenance cluster는 최소 한 개의 action/warm episode를 사이에 둔다.
- optional 미플레이를 실패/미완료처럼 표시하지 않는다.
- “Side 완료율 100%”가 M12 좋은 결과 조건이 되어서는 안 된다.

completionist payoff:
- M12에서 NPC가 윤서의 행동을 더 구체적 사건으로 기억.
- HRI07의 떠남 욕망이 M11 대사에 더 풍부하게 반사.
- Popsy/Seven/Bokhee가 자기 결정을 윤서 없이 했던 기억이 위임 장면을 더 믿게 함.
- 동일한 Main 결과라도 relationship texture가 달라짐.

## 8. PLAYER-MADE YUNSEO 데이터 원칙

M12에 필요한 것은 성향 점수 설명이 아니라 observable history다.

Main만으로 확보 가능한 예:
- 기다렸는가 / 먼저 움직였는가.
- 직접 했는가 / 맡겼는가.
- 기록을 지켰는가 / 사람을 먼저 뺐는가.
- 자기 몸을 또 비용으로 넣었는가.
- 모른다고 말했는가.

Optional은 추가 evidence를 제공하되, 새로운 personality truth를 만들지 않는다.

금지:
- “당신은 X형 윤서입니다.”
- 숨겨진 personality test 공개.
- optional 미플레이를 성격 공백으로 처리.
- M10 이전 PLAYER COMPLICITY 해설.
