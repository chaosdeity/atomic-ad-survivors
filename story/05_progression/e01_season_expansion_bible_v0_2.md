## 2. 윤서 최신 구조

윤서는 blank slate가 아니다. 플레이어는 윤서의 고정 중심을 지우지 않고 반복 행동의 기울기를 만든다.

장면 작성 순서:

```text
IMMUTABLE CORE
+ CURRENT WEIGHT / PRESSURE
+ CURRENT SITUATION
+ RELATIONSHIP MEMORY
+ 1 PRIMARY GLOBAL VECTOR
+ optional 1 SECONDARY GLOBAL VECTOR
+ CURRENT CHOICE
```

### 2.1 Global vectors 4

1. HOLD <-> COMMIT
2. SELF-ERASURE <-> SELF-PRESERVATION
3. CONTROL <-> DELEGATION
4. DISTANCE <-> ATTACHMENT

한 장면에서 네 축을 전부 설명하지 않는다.

### 2.2 Contextual trust

DISTRUST <-> RELIANCE는 전역 성격 수치가 아니다. 미나, 도윤, 팝시, 세븐, 복희, 에피소드 인물별 관계 기억으로만 남긴다.

### 2.3 Seasonal belonging

BELONGING <-> ESCAPE는 장면별 수치가 아니라 시즌 장기 궤적이다. M05-M08 개별 선택 하나로 소속 또는 탈출을 확정하지 않는다.

### 2.4 V0.1의 7개 축 처리

V0.1의 relationship / voice / interiority / support / trace / autonomy / revisit는 global vector로 사용하지 않는다.

필요하면 다음처럼 장면 표현 태그로만 사용한다.

- voice: 현재 global vector가 대사 리듬에 드러나는 방식
- interiority: 현재 pressure와 repair가 내면에 드러나는 방식
- support / trace / autonomy / revisit: 선택의 구체 행동 또는 후속 결과
- relationship: 대상별 contextual trust와 관계 기억의 표현

## 3. 윤서 invariant 적용

M05-M08에서 우선 적용할 최신 후보 invariant:

- 자기 개입이 타인의 역할과 선택을 덮을 수 있음을 경계한다.
- 선을 넘었을 때 의도 설명보다 개입 축소, 선택 복원, 후속 비용 부담으로 고친다.
- 사람을 캠페인 역할로 확정하기 전에 선택 가능한 상태를 확보하려 한다.
- 자기 이름과 보급소가 다음 관할 증거로 굳는 것을 경계한다.
- 필요한 사람이 되고 싶은 욕망 때문에도 잘못할 수 있다.
- 구체 새 피해자, 가족, 사망, 배신 과거를 윤서 과거로 추가하지 않는다.

## 5. Campaign별 보정 원칙

### M05 / C02

핵심은 patient state, care eligibility, isolation/discharge, actual capacity mismatch다. 번호표, 치료 순번, 대기열을 주 갈등 엔진으로 쓰지 않는다.

### M06 / C03

핵심은 custody / hold / release / destination / return flow다. 장비 호환은 윤서 과거 고용, 원소유, 제조 기원을 증명하지 않는다. R02/R08 공급 의존성을 새 graph 사실로 만들지 않는다.

### M07 / C04

핵심은 validity / authentication / charging / diagnosis / repair / operability다. 시설의 "정품" 판정은 시설 분류다. 팝시의 객관적 정체성 판정이 아니다.

### M08 / C06

핵심은 membership / account / transaction / tier / review / benefit entitlement / service access다. 포인트는 범용 세계 화폐가 아니다. slot은 구체 service access capacity 또는 entitlement claim에 연결하고 인간 비용을 먼저 보여준다.
