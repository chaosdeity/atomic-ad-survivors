## 1. REDUNDANCY AUDIT

분류:
- A: 세계의 핵심 motif. 유지하되 표면 문법은 다양화.

- D: 삭제/통합 권고. 장치 자체가 다른 장면의 기억을 깎음.

## 2. 반복 구조의 상위 위험

### 2.1 “윤리 문제 → 3지선다 → WRONG MOVE → 의외로 도움 주는 시스템 인물 → 비용 → 귀환 농담”

M05-M08에서 특히 선명하다. 각각 장면 자체는 좋지만 연속 소비 시 작가의 사고 순서를 플레이어가 먼저 예측하게 된다.

권고:
- M05: 구조 유지. care dilemma의 대표형.
- M06: choice를 관계 범위 선택으로 축소하고 공동 작업의 손맛을 앞세움.
- M07: Popsy가 final decision을 직접 한다는 형식을 유지. 이것 자체가 다른 편과 다름.
- M08: choice 수보다 군중·access 결과를 앞세우고 설명 문단을 단축.

### 2.2 provenance cluster

SS05 → HRI05 → M10 → SS12에 “출처를 잃은 기록의 권위”가 반복된다.

권고:
- SS05: 복희가 이름 없는 송장을 어떻게 느끼는지.
- HRI05: “보존”이 “붙잡기”가 되는 복희의 약점.
- M10: 사회적으로 유통되는 윤서 identity.
- SS12: 독립 episode보다 M10 aftershock로 축소/통합.

같은 철학이어도 각 편의 주어를 다르게 만들면 살아남는다.

## 3. SAME-WRITER PHILOSOPHY AUDIT

아래는 새 character bible이 아니다. 현재 원고가 실제로 보여주는 차이만 적는다.

### 3.1 윤서

| 항목 | 현재 원고가 증명하는 방식 | 근거 |
|---|---|---|
| 무엇을 먼저 본다 | 당장 손댈 수 있는 사람·문·물건·작업. 추상 원칙보다 “지금 내가 뭘 하면 되나”로 진입한다. | M01 응급키트/문, M04 컵과 문, M06 custody 작업 |
| 무엇을 참지 못한다 | 남이 자기 역할을 확정하는 것, “윤서는 원래/늘”로 굳히는 것. 동시에 쓸모없어지는 감각도 못 견딘다. | M06 role claim, M09 교대, M10 편집본, M12 기대 |
| 무엇을 잘못한다 | 급하면 손부터 나가고, 자기 몸/시간을 비용으로 넣고, 타인의 결정 범위를 앞질러 정한다. | M04 미나 이름 선사용, M05 강제 개입, M07 손을 뻗음, M12 다 떠맡기 |
| 사과 방식 | 짧게 인정한 뒤 행동 범위를 줄이고 선택권·후속 비용을 돌려준다. | M05 “내가 너무 빨랐어” 이후 중단, M09 카운터를 친 뒤 사과 |
| 화내는 방식 | 짧고 몸에 먼저 온다. “싫어”가 빠르고, M09에서는 카운터를 친다. | M06, M09 |
| 웃는 방식 | 피곤함, 관계의 찔림, 자기 모순이 들켰을 때 짧게 웃는다. | M05 귀환, M06 주임/도윤, M09 교대 |
| 도움 요청 방식 | 늦다. 먼저 혼자 해보고 능력 경계가 명확해진 뒤 구체적으로 부른다. | M04 야간 몸 이동에서 미나 호출, M12 위임 |
| 떠나는 방식 | 떠날 권리를 갖고 싶어 하지만 즉시 떠나는 결론은 피한다. “갈 수 있음”과 “지금 감”을 분리한다. | M09 “아예” 떠나고 싶음, M11 eligibility 욕망과 비동행 |
| 피로할 때 무너지는 방식 | 일을 더 맡아 과기능하거나 반대로 잠깐 사라지고 싶어 한다. | M04 야간 교대, M05 쉬고 싶음, M12 이불 속/모든 일 떠맡기 |

판정: 윤서는 철학 토론형 인물이 아니라 행동이 너무 빨라서 철학 문제가 생기는 인물이다. 이 차이가 유지되면 다른 캐릭터와 분리된다.

### 3.2 미나

| 항목 | 현재 원고가 증명하는 방식 | 근거 |
|---|---|---|
| 무엇을 먼저 본다 | capacity, 물, 침상, 약, 교대, 식사처럼 오늘 실제로 감당할 수 있는 양. | M05, M09, HRI06 |
| 무엇을 참지 못한다 | 비용을 숨기거나 “나쁜 역할”을 다른 사람에게 넘기는 것. | M08 공동 책임, M09 윤서와 충돌 |
| 무엇을 잘못한다 | 자기 몫을 뒤로 미루고 운영자가 되어 버리며, 설명하지 않은 생활 지식을 상대가 안다고 가정한다. | HRI01, M04 컵 위치 후 “내가 말 안 했네” |
| 사과 방식 | 감정문보다 “내가 말 안 했다”를 인정하고 바로 배치/업무를 고친다. | M04 |
| 화내는 방식 | 짧고 구체적이다. 문장·표·교대를 바로 고친다. | M09, HRI06 |
| 웃는 방식 | 생활의 허점이나 실패한 농담이 긴장을 찢을 때 웃는다. | HRI06, HRI07 |
| 도움 요청 방식 | “도와줘”보다 일을 잘라 배정한다. 자기 휴식은 부탁하기 어려워한다. | M04, HRI01 |
| 떠나는 방식 | 떠날지보다 “하루만 아무것도 세지 않는 곳”을 먼저 상상한다. | HRI07 |
| 피로할 때 무너지는 방식 | 자기 식사·잠·몫을 운영표 밖으로 밀어낸다. | HRI01, HRI06 |

판정: 미나는 자율성보다 먼저 capacity를 본다. 같은 결론에 도달해도 “누가 결정권을 가져야 하나”보다 “누가 오늘 밤 실제 부담을 지나”가 출발점이다.

### 3.3 도윤

| 항목 | 현재 원고가 증명하는 방식 | 근거 |
|---|---|---|
| 무엇을 먼저 본다 | 작동 방식, 손상, 신호, 수리 가능성. | M01, M06, SS10 |

| 무엇을 잘못한다 | 기술적 호기심이 사람의 경계보다 먼저 달리고, 불확실성을 장치로 닫고 싶어 한다. | M06, SS10 |
| 사과 방식 | 말보다 절차를 바꾼다. 손을 빼고, 먼저 묻고, 되돌릴 수 있는 범위를 만든다. | M06 RETURN, HRI03 |

| 떠나는 방식 | 바깥을 보고 싶다는 호기심을 솔직히 말하지만, 자신이 대체 가능하다는 말에는 서운해한다. | HRI07 |
| 피로할 때 무너지는 방식 | 기술 설명을 더 길게 하고 “장치가 답을 내게” 만들려 한다. | SS10, HRI06 |

판정: 도윤은 선택권 철학자라서 기다리는 것이 아니다. 좋은 기술자가 되려면 자기 손도 제한해야 한다는 식으로 배운다.

| 떠나는 방식 | “맡긴 것” 때문에 안 간다고 말하다가 그것이 전부 자기 것인가라는 질문에 멈춘다. | HRI07 |
| 피로할 때 무너지는 방식 | 보존 책임과 자기 정체성을 붙여, 놓는 일을 상실처럼 느낀다. | HRI05 |

판정: 복희는 “원본을 지켜야 한다”가 아니라 “사람이 사라지지 않게 하고 싶다”에서 출발한다. 그래서 M10에서 세븐과 같은 provenance 결론에 도달해도 이유가 다르다.

### 3.6 팝시

| 항목 | 현재 원고가 증명하는 방식 | 근거 |
|---|---|---|
| 무엇을 먼저 본다 | 문장의 리듬, 자동 발화 여부, 버튼이 자기 요청을 되돌릴 수 있는지. | SS06, HRI03, M07 |
| 무엇을 참지 못한다 | 원하지 않는 자동 말, 침묵을 고장으로 취급하는 시선, “잘못 좋아한다”는 표정. | HRI03, SS06 |
| 무엇을 잘못한다 | 삭제를 한 번의 영구 해방처럼 생각했다가 빈칸이 무서워지고, 익숙한 역할을 좋아하면 후퇴라고 스스로 의심한다. | HRI03, SS06 |
| 사과 방식 | 결정을 바꾼 것 자체를 사과하지 않고 새 요청을 정확히 말한다. | HRI03 |
| 화내는 방식 | 존댓말을 유지한 채 정확히 선을 긋거나 직접 연결을 끊는다. | SS06, M07 |
| 웃는 방식 | 광고 문법을 자기 농담으로 훔쳐 쓰고, 실패한 시스템 문구를 비튼다. | SS06 |
| 도움 요청 방식 | 한 번에 못 말하고 작업대 앞을 몇 번 지나간 뒤 구체적으로 요청한다. | HRI03 |
| 떠나는 방식 | 큰 탈출 철학보다 “여기 충전 순서를 고치고 가고 싶다”는 생활 WANT로 답한다. | HRI07 |
| 피로할 때 무너지는 방식 | 익숙한 자동 문구/리듬으로 돌아가거나, 그것을 전부 지운 빈칸을 두려워한다. | M07, HRI03 |

판정: 팝시는 “자율성”을 추상 권리로 말하지 않는다. 오늘 어떤 문장을 자기 입으로 쓸지, 내일 다시 바꿀 수 있는지가 핵심이다.

## 4. SAME-WRITER 최종 판정

PASS WITH EDITORIAL RISK.

여섯 인물은 같은 결론에 도달하는 이유가 실제로 다르다.

- 윤서: 행동과 역할 고착의 위험.
- 미나: 유한한 capacity와 숨은 운영 비용.
- 도윤: 기술적 신뢰성과 허용 범위.
- 세븐: 데이터/분류의 한계.
- 복희: 사람과 흔적을 지우지 않되 소유하지 않는 문제.
- 팝시: 말과 선택을 다시 바꿀 수 있는 생활 자율성.

문제는 철학 자체가 같아서가 아니라, 작가가 그 차이를 종종 같은 문장 틀로 번역한다는 점이다. “같은 말 아니다”, “알아”, “싫어”, “기록하지 마”, 마지막 웃음이 그 차이를 평평하게 만든다.

편집 우선순위는 character bible 추가가 아니라 표면 문법의 분산이다.
