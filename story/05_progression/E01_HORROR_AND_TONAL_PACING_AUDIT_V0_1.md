## 1. 공포 상승 결론

현재 E01에는 필요한 다섯 층이 모두 있다.

UNCANNY
→ PERSONAL

문제는 층이 없는 것이 아니라, M07 전후부터 IDENTITY / PLAYER COMPLICITY의 설명 언어가 너무 일찍 보인다는 점이다.

권고 핵심:
1. M01-M04: “이상한 시스템과 사람의 실제 생활”을 본다.
2. M05-M09: 관계와 역할이 사람 사이에서 굳어지는 공포를 체험한다.
3. M10: 처음으로 “윤서 이야기가 윤서를 대신한다”는 IDENTITY horror를 명시적으로 전면화한다.
4. M12: 처음으로 플레이어 자신의 반복 행동이 사회적 윤서를 만들었다는 PLAYER COMPLICITY를 정면화한다.
5. M10 이전 내부 vector / meta label은 production에서 플레이어에게 설명하지 않는다.

## 3. M10/M12 보호를 위한 CUT / SOFTEN 권고

실제 원고는 이번 작업에서 수정하지 않는다. 아래는 PM 승인 후 production 편집 대상이다.

### M07

현재 내부 문구의 “CONTROL 성향이 강하게 누적된 윤서” 같은 label은 writer-facing logic으로는 유효하다. 플레이어-facing 설명으로 노출되면 M12가 “게임이 나를 분류하고 있었다”는 사실을 너무 일찍 알려준다.

권고:
- label 노출 CUT.
- 팝시가 윤서의 반복 행동을 기억해 “윤서 씨”라고 제지하는 장면만 남김.
- 시스템이 player vector를 알고 있다는 암시는 주지 않음.

### M08

REVISIT CONSEQUENCE의 “M12 PLAYER-MADE YUNSEO 씨앗” 같은 설명은 production-facing note로만 유지.

권고:
- 플레이어는 단지 “그날 다 꺼버린 사람” 같은 사회적 기억을 듣게 한다.
- 그것이 후속 identity system의 씨앗이라는 설명은 M12까지 금지.

### SS06

“시설 claim이지 진짜 정체 판정이 아니다”는 안전장치가 여러 번 반복되면서 역으로 identity question을 강조한다.

권고:
- 한 번만 명확히 하고 이후는 팝시가 박자 일부를 좋아하는 행동으로 보여줌.
- 이 편의 중심은 “과거에서 온 것을 좋아해도 현재 선택일 수 있다”이지 “진짜 팝시는 누구인가”가 아니다.

### SS14

M11과 M12 사이에서 “원하는 결론과 증거”를 다루는 좋은 장면이지만, 윤서 과거/빈자리/identifier가 너무 가까이 오면 M12의 사회적 identity horror와 경쟁한다.

권고:
- DEEP LORE OPTIONAL.
- 첫 플레이 추천 노출 OFF.
- 플레이 시에도 윤서 과거 truth보다 “둘 다 같은 답을 원한다”는 관계 장면을 중심으로 읽는다.

## 4. TONAL PACING 위험

### 경고 A: 초반 rest 3연타 가능성

SS01 + HRI01 + M04를 모두 연속 소비하면 세 편 모두 낮은 온도로 느껴질 수 있다.

대응:
- SS01 플레이 시 HRI01은 자동 강제하지 않음.
- M03 사이에 하나의 rest만 기본 추천.

### 경고 B: M05-M08 윤리 토론형 구조 반복

M05, M06, M07, M08 모두:
상충 가치 설명 → 선택 → 잘못된 빠른 해결 → 비용 → 귀환
의 뼈대가 있다.

대응:
- SS04/SS06/SS08 같은 물리·코미디 side를 사이에 한 편씩 선택 노출.
- M06은 손 작업과 도윤 관계를 전면.
- M07은 Popsy가 최종 결정을 직접 말하는 장면을 전면.
- M08은 군중과 access 결과를 전면.

### 경고 C: SS05-HRI05-M10-SS12 provenance fatigue

기록/출처를 좋아하는 플레이어도 네 편을 연속으로 읽으면 같은 질문처럼 느낄 수 있다.

대응:
- HRI05는 M08 이후로 충분히 띄우고 개인 욕망 중심.
- SS12는 M10에 MERGE 후보.
- M10이 유일한 major identity/provenance peak가 되게 함.

### 경고 D: SS10-HRI06-M09 procedural uncertainty 3연타

셋 다 “모른다는 걸 어떻게 운영할 것인가”를 다룬다.

대응:
- first-play optional 노출은 SS10 또는 HRI06 중 하나만 강하게 추천.
- completionist에게는 SS10=기계, HRI06=사람이 읽는 문장, M09=실제 문 운영이라는 차이를 UI description에서 분명히 한다.

### 경고 E: 후반이 계속 무거워질 위험

M10 → SS12 → SS13 → M11 → SS14 → M12를 전부 하면 정적 윤리/미스터리 압력이 길다.

대응:
- HRI07을 M11 직전에 기본 경로에 둔다.
- SS14는 default OFF.
- SS12는 merge 후보.
- M11 이후 M12까지 너무 많은 lore를 끼우지 않는다.

## 5. TONAL RULE OF THREE

강도가 비슷한 3편 이상을 강제 연속시키지 않는다.

Production recommendation:
- horror/tension 3연타 금지.
- quiet ethics 3연타 금지.
- warm/rest 3연타 금지.
- 같은 “3지선다 윤리 토론” 2편 연속도 가급적 금지.

이 규칙은 세계의 새 dependency가 아니라 콘텐츠 큐 편집 기준이다.
