# 사건 v3 — 가설 검증과 반복되는 사물

최신 플레이 파일: playtest-v3.html.
실행 중인 로컬 주소: http://127.0.0.1:8767/playtest-v3.html (해당 PC에서만 접속).
v2 HTML은 보존했다. 화면 생성 스크립트는 v3용이며 기존 산출물을 덮어쓰지 않는다.

## 보강한 부분

- 시작의 열린 문과 퇴원 축하 안내가, 반전 후에는 '누구의 치료가 끝나는가'라는 질문으로 다시 읽힌다.
- 재원 확인 시각과 외부 수령 시각 사이의 십 분을 실제 대조 대상으로 만들었다.
- 비어 있는 종이봉투는 선택 관찰→기록 확인→마지막 행동을 이어주는 사물이다.
- 퇴원 가능 표기가 오류라는 가설을 검사할 수 있다. 증거로 기각되며 비용·신뢰 벌점은 없다.
- 질문 전에 주민을 관찰하면 짧은 대화가 열린다. 자원 보상이 아닌 인물 이해를 위한 선택이다.
- 강제 인양 이후의 대화는 그 행동을 기억한다. 독립 퇴원이 같아도 두 사람의 거리와 마지막 말이 다르다.
- 잔류에서는 문틈과 봉투 소리가 남고, 조건부 퇴원에서는 같은 시각의 알림이 윤서에게 옮겨온다.
- 보급소 몫과 대체 치료 사이의 실제 자원 선택은 유지한다. 결말 이름만 추가하지 않았다.

## 검증 결과

verify.py: 10/10, results-20260906-053934-341706/REPORT.md 및 results.json.
도달 가능한 상태 450개, 전이 1,092개 전수 검사. 종결 경로 없는 상태 0.
quality_probe.py: 5/5. 기회비용과 행동 이력 반영 검사.
narrative_probe.py: 6/6. 가설 기각 후 진행, 조사 비용 없음, 반복 입력 차단,
선택 관찰의 회수와 비필수성, 대화의 보상 비의존성, 늦은 대화의 강제 인양 기억 검사.
합계 21개 기능·정보 순서 검사 통과. 이 숫자는 문학성·재미 평점이 아니다.

브라우저에서 v3 시작→병상 표찰→가설 검증을 직접 조작했고 해당 화면의 텍스트 배치를 스크린샷으로 확인했다.
v3의 전체 종결 경로는 Python 전수 검사 대상이며, 이번 브라우저 확인에서 모든 결말을 클릭하지는 않았다.
Godot·모바일 화면·음성·음악·전투는 검증하지 않았다. 축하음은 텍스트 묘사이며 실제 음원은 없다.

## 주관적 품질과 범위

새 결말이나 반전을 무작위로 추가하지 않았다. 세 합의의 조건은 동일하다.
사물의 반복과 의미 변화, 인물의 침묵과 구체적 행동을 보강했지만,
내용을 모르는 사람의 재미·놀라움·감정 평가는 아직 0건이다. 성공 판정은 보류한다.
장기 후속 의무와 보급소의 이후 생활은 이번 짧은 사건 바깥이다.

실제 읽음: failure-ledger.md, story.py, build_playtest.py 관련 부분.
작성·실행: narrative_probe.py. 기존 verify.py와 quality_probe.py는 수정 없이 실행.
수정: story.py, build_playtest.py, README.md, failure-ledger.md.
생성: playtest-v3.html, narrative_probe.py, 이 문서, 고유 검사 결과 폴더.
