==================================================
[윤서 — 핵심 재분리]
==================================================

윤서의 중심은 "증거주의자"가 아니다.

윤서가 먼저 보는 것:
**자기가 잘못 이름 붙일 가능성.**

윤서가 두려워하는 것:
자기 말이 타인의 역할을 고정해 버리는 것.

윤서의 오류:
확신을 기다리느라
현재 필요한 행동까지 늦춤.

윤서의 책임 방식:
자기 몸과 자기 노동을 비용에서 빼 버림.

윤서의 갈등 전술:
범위를 좁히고,
자기가 직접 맡을 작은 행동으로 내려감.

윤서가 틀렸을 때:
설명보다 **다시 가거나 직접 손을 댄다.**

따라서 윤서의 대사가
세븐처럼 "근거가 부족하다"로만 흘러가면 FAIL.


==================================================
[세븐 — 핵심 재분리]
==================================================

세븐의 중심은 "신중한 사람"이 아니다.

세븐이 먼저 보는 것:
**정보가 어디서 복제되었는가.**

세븐이 두려워하는 것:
같은 원본의 복사본을
여러 독립 증거로 세는 것.

세븐의 오류:
구조를 너무 잘 정리해서
사람의 긴급함을 늦출 수 있음.

세븐의 책임 방식:
자기 결론이 다시 검증 가능하도록
원문과 변환 경로를 남김.

세븐의 갈등 전술:
상대의 결론을 반박하기보다
근거 계보를 해체함.

세븐이 틀렸을 때:
자기 분류를 수정하고
왜 틀렸는지 추적 가능하게 남김.

세븐이 행정 심사관처럼
"확정할 수 없습니다"만 말하면 FAIL.


==================================================
[미나 — 핵심 재분리]
==================================================

미나가 먼저 보는 것:
**오늘 부족한 손, 자리, 음식, 시간.**

미나의 위협:
아무도 결정을 안 해서
실제 노동이 특정 사람에게 몰리는 것.

미나의 오류:
쓸 수 있는 답을 너무 빨리 요구함.

책임 방식:
계산한 몫을 자기 일정과 몸으로 떠안음.

갈등 전술:
질문보다 **할 일을 상대 앞에 놓음.**

틀렸을 때:
사과보다
배분/순서/자기 몫을 실제로 바꿈.

복희처럼 '어떻게 보관할까',
윤서처럼 '어디까지 맞나'를 먼저 묻지 않는다.


==================================================
[복희 — 미나와 분리]
==================================================

복희가 먼저 보는 것:
**누가 맡겼고, 다시 찾으러 올 수 있는가.**

위협:
없애도 된다는 권한 없이
흔적을 소모하는 것.

오류:
남겨야 한다는 마음 때문에
공간과 노동 비용을 과소평가.

책임:
보관하기로 했으면
자기 손과 공간을 씀.

갈등:
"버리지 마"가 아니라
"누가 다시 찾을 때 뭘 내줄 건데?"로 묻는다.


==================================================
[장도윤 — 윤서와 분리]
==================================================

도윤이 먼저 보는 것:
**증상과 물리 원인.**

위협:
원인을 모른 채 임시로 버티다
더 크게 망가지는 것.

오류:
고칠 수 있다는 이유로
먼저 만짐.

책임:
자기가 손댄 것은
자기가 다시 열고 고침.

갈등:
상대의 말보다
시험 동작을 제안.

틀렸을 때:
논쟁하지 않고
손을 떼거나 부품을 되돌림.

도윤이 윤서처럼
사실 범위를 관리하는 대사만 하면 FAIL.


==================================================
[ROOM-12 — 다른 돌봄 캐릭터와 분리]
==================================================

ROOM-12의 중심은
"자기결정권을 말하는 환자"가 아니다.

ROOM-12가 먼저 보는 것:
**자기가 손을 떼면 다른 사람의 생활이 어떻게 끊기는가.**

위협:
자기 한 사람의 자유를 위해
다른 사람의 저녁/생활이 멈추는 것.

오류:
자기 욕구를
다른 사람의 필요 뒤에 계속 숨김.

책임:
자기 자리를 실제 노동으로 유지.

갈등:
추상적으로 "내 선택"을 말하기보다
"그러면 다음 밥은 누가 받아요?"처럼
구체적인 연쇄를 상대에게 돌려줌.

변화:
후반에는
"다른 사람 때문에"가 아니라
"나는 오늘 밖에서 먹고 싶어요"라고
자기 주어를 회복.

병실 환자와 같은 자기결정권 화법만 쓰면 FAIL.


==================================================
[병실 환자 — ROOM-12와 분리]
==================================================

병실 환자의 중심:
**자기 요청을 더 큰 퇴원/이주 이야기로 과대해석하지 못하게 하는 것.**

먼저 보는 것:
자기 컵, 창가, 몸의 위치, 오늘의 작은 선택.

위협:
작은 부탁이
'퇴원하고 싶다', '여기 살고 싶다' 같은
큰 결정으로 번역되는 것.

오류:
반복적으로 무시당해
설명 자체를 포기할 수 있음.

갈등:
상대에게 자기 말을 다시 정확히 써 달라고 요구.

ROOM-12처럼
타인의 다음 식사 노동을 중심으로 말하지 않는다.


==================================================
[가족심사 관리자 — 퇴원 심사 대리와 분리]
==================================================

가족심사 관리자는 기계적이다.

핵심:
**빈자리를 역할로 채우면 돌봄이 지속된다.**

언어:
매끄럽고 친절.
편의와 역할 수락을 같은 문장에 묶음.

절대:
피곤함
책임 회피
인간적 짜증
개인적 두려움

없음.

퇴원 심사 대리처럼
"누가 밤을 맡습니까?"라는 실제 노동 질문에 머물지 않는다.


==================================================
[퇴원 심사 대리]
==================================================

인간이다.

핵심:
**내보낸 뒤 무너지면 누가 책임지는가.**

먼저 보는 것:
실제 야간 인력, 인계, 돌봄 공백.

위협:
좋은 말만 하고
실제 책임자가 없는 퇴원.

오류:
그 두려움 때문에
작은 자유까지 모두 보류.

언어:
공식적일 수 있으나
피로와 방어가 드러남.

가족심사 관리자처럼
자리를 채우면 자동 해결된다고 말하지 않는다.
