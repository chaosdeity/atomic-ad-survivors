# 광고세계 규칙 실험 01

세계관 확정이나 기존 게임 변경이 아닌 독립 Python 시뮬레이션이다.
추가 AI 호출, 설치, 네트워크 연결, 외부 라이브러리는 사용하지 않는다.

## 실행

이 폴더에서 Python 3.11 이상으로 실행한다.

```powershell
python simulator.py
python verify.py
```

simulator.py는 시설 파괴 → 대응 → 패배 → 치료 조건 수락 사례를 출력한다.
verify.py는 제한된 계약 검사와 고정 시드 사건 검사를 실행한다.
매번 고유 results 폴더를 만들며 이전 결과를 덮어쓰지 않는다.

## 구현한 규칙

- 캠페인 2개, 지역 하나를 추상화한 공간, 윤서와 필요가 다른 NPC 3명.
- 생명 유지·구조·조건부 치료와 보급소/동료의 구조 수단 소모.
- 관측된 시설 파괴에 대한 다음 턴 대응과 자원/협력 관계에 따른 분기.
- 실제 자원 부족 시 대응 취소. 중복 사건 처리 방지.
- 식량/치료 필요에 따른 NPC 선택과 조건으로 판정하는 작은 결말.
- 시간 경과만으로 성공을 취소하지 않음. 실제 경로 손실은 결과에 반영.

## 아직 구현하지 않은 것

- Godot 전투, 이동, 화면, 재미·난이도·가독성 검증.
- 비상 보존 선택을 실제 Godot 화면과 전투에 연결하는 작업.
- 치료 관할 이후의 갈등·협상·보증 연쇄. 현재는 지원자의 치료 경로와 해당 NPC 조건부 등록까지 연결.
- 확정 편입, 기억 보정, 관계 보증 연쇄, 서비스 소비·유지 비용, 감시망 발견.
- 관측되지 않은 시설 파괴를 나중에 발견하는 점검 시스템.
- NPC 자율 이동/협상: 현재는 치료 우선 주민의 경로 수용과 필요 기반 선택 함수만 구현.
- 구조 시간을 비교하는 경쟁: 현재는 보급소→동료→캠페인 우선순위.

따라서 불사 설정은 일부 상태 전이에만 적용한 실험 가정이다.
일반 자원이 없는 생명 유지 상태에는 request_preservation → wait 3회 → wake 복귀 경로가 있다.
available_actions()가 현재 수행 가능한 행동을 반환하고 recovery_offer()가 사전 비용 안내를 제공한다.
요청은 위치 신호 노출을 1 증가시키고, 기상은 해당 캠페인 조건부 등록을 적용한다.
수락 없이 자동 등록하지 않으며, 중복 요청이나 조기 기상으로 시간을 건너뛸 수 없다.
복구 도중 보급소 인양이 가능해지면 escape로 벗어나 후속 복구를 취소한다.

중요한 실험 가정: 일반 치료망과 별개인 최저 보존 설비가 유지되고, 개인별로 턴당 복구 에너지를
보충할 수 있다. 이 설비는 일반 supplies와 별개이며 이번 실험에서 파괴 대상이 아니다.
그 설비와 보충 에너지까지 모두 사라지는 세계에서는 복귀를 보장하지 않는다.
3턴은 시뮬레이션 시간이며 실제 게임의 강제 대기 시간이 아니다.
신호 노출은 누적 기록이고 추가 추적 패턴과는 아직 연결하지 않았다.
우회 식량 경로는 유지 가능한 것으로 추상화했으며 영구 무한 식량의 세계관 확정이 아니다.

## 수정 2회차: 시설과 주민 치료의 인과 연결

simulator.py에 치료 제공자와 주민 치료 경로를 연결했다. 시설 상실→치료 보류,
자체 복구→기존 관할 치료, 지원 복구→지원 캠페인의 조건부 치료로 바뀐다.
establish_care를 치료 의존 주민에게 실행하면 보급소 자원 2를 써 대체 치료를 확보한다.
이후 npc_choice가 독립 경로를 선택하며, 과거 등록 기록을 임의로 지우지 않는다.
단순 치료 보류는 사망이나 새로운 엔딩이 아니다.

재실행: python verify.py / python evaluate_layers.py.
기존 검사 20/20: results-20260906-005832-413247/REPORT.md.
인과 검사 10/10: layer-evaluation-20260906-005832-678306/REPORT.md.
같은 256개 초기 조건에서 파괴 전략과 비파괴 전략의 치료 결과 차이 96/256=37.5%.
실제 플레이 확률이 아니며, 두 캠페인의 초기 자원이 같도록 구성한 벤치마크다.
이 벤치마크에서는 타 캠페인 치료가 0회다. 자원을 비대칭으로 둔 별도 인과 검사에서 지원 이전을 검증했다.
독립 치료 또한 기존 네 전략에는 개설 행동이 없어 0회다. 별도 비용·선택·20턴 유지 검사로 검증했다.

실제 읽은 파일: simulator.py, evaluate_outcomes.py, failure-ledger.md, README.md,
생성된 layer-evaluation 보고서. 실행한 기존 verify.py는 수정하지 않았다.
변경: simulator.py, README.md, failure-ledger.md. 생성: evaluate_layers.py와 고유 결과 폴더.
수정·재검증 누적 2/2회. 기존 프로젝트 연결·세계관 확정·Godot 실행은 수행하지 않았다.
