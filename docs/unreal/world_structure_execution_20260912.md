## 목표와 승인 범위

사용자의 로드맵·로직 작성 및 실행 요청을 이어간다. 최신 지적에 따라 R08 보급소를 광고 주거 자동화로 취급한 해석을 폐기한다. 기존 시나리오 구조를 유지하여 Unreal의 장소·운영 방식·적 출처를 구분한다. 새 세계 설정을 창작해서 기존 잠금을 바꾸지 않는다.

허용 작업: 관련 정사 대조, 파생 데이터·제작 검사 도구·작업 기록 작성. 이후 맵 제작은 아래 장소별 순서와 기존 아트 게이트를 따른다. 원본 샘플 맵 저장, 기존 에셋 삭제/이동, 커밋, 미승인 아트의 최종 승격은 하지 않는다. 사용자가 승인한 실행 범위 내의 가역적인 준비 작업은 추가 허락을 반복 요청하지 않는다.

## 수정한 해석

- 세계는 실제 지구를 바탕으로 한다. 전 지구 12개 광역권 E01–E12, 광역권마다 8개씩 96개 정식 캠페인 E##_C##, 그 아래 실제 플레이 노드를 구분한다. 96개 캠페인이 96개 완성 레벨이라는 뜻은 아니다.
- E01은 R01–R08의 8개 플레이 권역, 40개 로컬 노드, 37개 연결이다. 첫 제작 P0는 5개다. 나머지 광역권의 세부 플레이 지도를 E01과 똑같이 복제하지 않는다.
- R08은 침묵권이다. E01_C08 표기는 옛 비상보급·대피 인프라와의 역사적 연관이다. 침묵권 자체가 광고 캠페인이거나 현재 자동화로 운영된다는 뜻이 아니다.
- 보급소는 기존 주유소·편의점·소형 변전소와 신호 음영을 생존자들이 고쳐 쓰는 곳이다. 수동 발전, 유선 장비, 차폐, 부족한 침상, 손으로 수정하는 정산과 생활 흔적이 공간의 주체다. 옛 광고 흔적과 현재 시설 운영을 분리한다.
- R01은 별도의 주거 캠페인 구역이다. 자동문·응급 키트·수령 로그·세대 인증은 그곳의 행동과 공간에 연결한다. R01 내부의 침묵 포켓에도 일괄 적용하지 않는다.
- 사람의 부재를 빈 공간으로 표현하더라도 모든 생물학적 인간이 죽었다는 새 설정으로 바꾸지 않는다. R08의 적은 생존자 생활은 유지한다. HP 0 역시 시나리오의 긴급 물리 회수이며, 기존 테스트의 death 용어는 최종 경험의 의미가 아니다.
- 자연은 장소별 지형/방치의 일부다. 숲이 침묵권의 원인이거나 전 세계가 같은 정글이라는 해석을 하지 않는다.

## 구현한 제작 데이터와 검사

`tools/build_unreal_world_contract.py`는 정사 표와 기존 E01 JSON을 읽어 `unreal/AtomicAdSurvivorsUE/Content/World/world_structure_v01.json`을 재현 가능하게 생성한다. 입력 불일치와 참조 오류를 실패 처리한다.

`campaignId`만으로 현재 운영 방식을 결정하지 않는다. `environmentKind`를 별도로 기록한다. `residentialAutomationAllowed`는 residential_campaign만 true이며, R08 전체와 R01-L04는 false다. 의료·물류·산업 등에도 주거 자동화를 일괄 허용하지 않는다.

모든 `ambientEnemySpawningAllowed`는 배치 증거가 준비되기 전까지 false다. 이는 전 세계에 적이 없다는 정사 변경이 아니라 임의 출현을 막는 제작 기본값이다. 위협을 도입할 때 출처 오브젝트·허용 표면·보행 경로·금지 경계·시나리오 시점을 함께 검증해야 한다.

이 JSON은 현재 제작용 계약이다. 기존 C++ 전투 모드가 이 데이터를 소비하도록 연결된 것은 아니며, 이 파일만으로 기존 샘플의 스폰이 변경되었다고 주장하지 않는다.

`Content/Python/validate_authored_world.py`는 에디터의 AAS 의미 액터 태그를 읽어 장소와 역할을 대조한다. 일반 조명/장식은 제외하고, 비어 있는 맵·잘못된 장소·누락/중복 역할·보급소의 주거 자동화·미승인 ambient_spawn을 거부한다. R08-L01만 검사할 수 있으므로 세 장소가 한 레벨에 있어야 한다는 가정을 하지 않는다. Unreal Python에서 `import validate_authored_world as v` 후 `v.run_editor_validation({"R08-L01"})`로 단독 허브 검사를 호출한다. 반환 오류 목록을 확인하며 성공 로그는 TAG_CONTRACT_PASS다. 이 에디터 연결 자체는 아직 엔진 안에서 실행하지 않았다. 태그가 올바르다는 사실은 실제 형상이나 기능이 구현되었다는 증거가 아니다.
