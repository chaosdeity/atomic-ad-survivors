# R01-L01 Unreal 대표 장면 제작 게이트 v0.1

상태: 제작 입력 잠금, 시각 PASS 미검증  
대상: `R01_VisualPilot`, 1920×1080 실제 게임 카메라  
장면: 도움을 받은 윤서가 세대 인증 기록에 접근하며 첫 전투를 맞는 순간  
작성 기준일: 2026-09-10

## 0. 판정

참조 화면에서는 사선 동선, 작은 인물 주변의 열린 플레이 공간, 가장자리 밀도, 자연스러운 재질·그림자 관계만 참고한다. 숲, 하천, 캠프, 게임 전제는 가져오지 않는다.

R01-L01은 최근 붕괴한 폐허나 숲 생존 구역이 아니다. 장기간 수선·갱신된 한국 서부 수도권 주거/분양 생활 자동화 생태다. 윤서는 이 질서를 이미 아는 현장 회수자이며, 유저가 첫 조작을 통해 배운다.

현재 `r01_visual_pilot_camera_v02_1280x720.png`는 카메라·캡처 경로만 확인한 블록아웃이다. 상자 주택, 막대 소품, 평면 재질, 노출된 지면판 때문에 시각 품질 증거로 사용하지 않는다.

## 1. 카메라와 화면 흐름

- 1920×1080 실제 플레이 카메라를 사용한다. 시작 후보는 지면 하향 50~60도와 완만한 원근이며, FOV와 높이는 정상 속도 가독성을 보고 고정한다.
- 윤서의 공식 신장은 `166.4cm`다. 임시 메시를 사용할 때도 바닥부터 머리까지 이 높이로 정규화하며, 남성 마네킹의 원본 크기를 윤서 설정으로 취급하지 않는다.
- 윤서는 화면 `(50%, 58%)` 부근, 투영 신장 70~100px를 초기 검토 범위로 둔다. 시야를 과도하게 좁혀 키우지 않는다.
- 회수 차선은 좌하단에서 중앙으로, 세대 인증 기록 패널은 우상단으로 시선을 잇는다.
- 윤서 주변은 이동·위협 식별 공간으로 비우고, 주택과 서비스 설비는 양옆에 밀도를 만든다.
- 전경 20%는 낮은 담장과 차선 경계, 중경 55%는 윤서·도움·첫 전투·기록, 후경 25%는 반복 수선된 주거 입면으로 구성한다.
- 하늘, 지면판 끝, 디버그 형상은 최종 판단 프레임에 노출하지 않는다.

## 2. 화면에 반드시 보이는 10개 요소

1. 성인 서브컬처 히로인으로 읽히는 윤서: 비대칭 의상, 스캐너, 반품 도장, 회수선 릴.
2. 외곽 회수 차선과 회수선 말뚝: 돌아갈 방향을 물리적으로 보여준다.
3. 반복 보수된 낮은 담장: 낡은 바탕과 교체 부재의 시간차를 보인다.
4. 한국 서부 수도권 기반의 반복 주택 입면: 창호·현관·설비·덧댄 표면으로 지속 사용을 보인다.
5. 실제 작동 중인 열린 자동문: 폐가가 아니라 도움을 제공하는 생활 시스템이다.
6. 자동문 근처의 응급 키트: 파밍 상자가 아니라 캠페인이 제공한 실익이다.
7. 응급 서비스와 인접한 수령 로그: 도움과 윤서 역할 후보 기록의 관계를 보인다.
8. 오래된 공공 안내판: 기존 안내 위에 스마일홈 갱신 라벨과 세대 보정 흔적이 겹친다.
9. 우상단의 세대 인증 기록 패널: 덮인 기록과 남은 기록의 층을 보이며 이번 출격의 조사 목적이 된다.
10. 우편함과 접근하는 판촉 전단: 생활 설비의 호출이 위협으로 이어짐을 형태로 읽힌다.

작은 로그 전문을 읽어야만 이해되는 구성은 반려한다. 자동문·키트·수령 로그의 인접 관계와 패널의 덮어쓰기 흔적이 먼저 읽혀야 한다.

## 3. 빛, 색, 시간 표현

- 건조한 지면과 옅은 구름을 통과한 사광을 기본 후보로 둔다.
- 부드러운 그림자와 충분한 간접광으로 현관 내부와 윤서의 어두운 의상이 뭉개지지 않게 한다.
- 생활 표면은 따뜻한 회백색, 도로는 중성 회색, 식생은 절제된 녹색으로 둔다.
- 코랄은 윤서의 도장 계열 강조에 제한한다. 서비스 상태색은 기존 상태 의미를 확인한 뒤 적용한다.
- 전면 녹·잔해·연무가 아니라 오래된 바탕 위에서 계속 작동하는 새 부품이 시간의 증거가 되어야 한다.

## 4. 무료 Fab 후보 적응 규칙

정확한 목록과 권리 기록은 `unreal/AtomicAdSurvivorsUE/AssetPipeline/r01_fab_pilot_manifest.json`을 따른다.

- `Modular Housing Basic`: 구조 부품으로만 쓴다. 완성 배치, 넓은 잔디 앞마당, 독립 차고, 동일 박공지붕을 그대로 사용해 미국 교외로 읽히면 반려한다.
- `Asphalt Road`: 실제 크기의 도로 표면과 국소 보수 흔적에 쓴다. 포함 차선이나 표식을 정사로 채택하지 않고 R01 표시를 별도 제작한다.
- `Wild Grass`: 담장 밑과 비통행 경계에 제한적으로 쓴다. 윤서 발밑, 회수 차선, 적 실루엣을 덮지 않는다.
- `Elderberry`: 관리된 울타리와 방치된 경계의 변형에 쓴다. 수종을 정사로 확정하지 않고 숲처럼 화면을 지배하지 않게 한다.

무료 표시는 상업권 검증 완료를 의미하지 않는다. 획득 당시의 정확한 라이선스와 `/Game` import 경로를 매니페스트에 기록해야 한다. `Allows usage with AI: No`인 에셋은 게임 제작·수동 편집에만 사용하고 생성형 AI 입력이나 학습 자료로 보내지 않는다.

## 5. 즉시 반려 조건

- 최근 재난 폐허, 일반 미국 교외, 숲 생존 게임이 먼저 읽힌다.
- 한글 간판만 붙여 한국성을 대신한다.
- 동일 주택 복제, 평면 재질, 막대형 소품 또는 디버그 선이 화면을 지배한다.
- 윤서가 점·막대로 보이거나 배경에 묻힌다.
- 과도한 발광이 위협과 서비스의 차이를 없앤다.
- L02, 첫 보스, 배수로, 가짜 귀환로를 첫 출격의 직접 목표로 앞당긴다.

## 6. 1920×1080 PASS 게이트

- [ ] 지정 게임 카메라로 렌더한 정확한 1920×1080 프레임이다.
- [ ] 맵, 카메라 transform/FOV, 품질 프리셋, 조명 방식, 재질 상태가 결과와 함께 기록된다.
- [ ] 원본 크기에서 10개 요소와 `윤서 → 위협 → 기록 대상` 시선 순서가 읽힌다.
- [ ] 장기간 수선·갱신되는 한국 주거/광고 자동화 생활권으로 읽힌다.
- [ ] 판단 영역을 지배하는 플레이스홀더가 없다.
- [ ] 윤서, 적, 위험, 장비, VFX가 서로 구별된다.
- [ ] 재질 스케일, 접지, 그림자, 표면 반복, 발광, 노출을 직접 검사했다.
- [ ] 같은 카메라의 정상 속도 플레이에서도 가독성을 확인했다.
- [ ] 측정 조건과 프레임 타이밍을 기록하고 프로젝트 성능 예산과 비교했다.
- [ ] 모든 외부 에셋의 권리 근거와 수정 이력을 기록했다.
- [ ] 사용자 아트 승인과 정확한 런타임 승격 승인을 별도로 받았다.

## 7. 아직 검증되지 않은 것

- 무료 Fab 후보의 실제 프로젝트 import 경로와 UE 5.8 호환 상태
- 모듈 주택 팩의 실제 구성과 R01용 재조립 가능성
- 1920×1080 최종 카메라의 실제 FOV, 윤서 투영 크기, 정상 속도 전투 가독성
- Lumen 품질과 RTX 4080 SUPER 기준 프레임 타이밍
- 윤서 3D 마스터, 적, VFX가 들어간 최종 화면 품질
